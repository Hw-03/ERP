# 생산 가능 수량 OS 라이센스 라벨 제외 설계

## 확정 범위

- 품목 코드 `4-PR-0058`(OS라이센스 라벨)은 BOM에 계속 포함한다.
- 재고, BOM 조회, 실제 조립 및 출하 처리에는 영향을 주지 않는다.
- 생산 가능 수량의 AF 기준 세 값인 출하 대기, 빠른 생산, 총생산을 계산할 때만 해당 품목의 필요 수량을 무시한다.
- 이 규칙은 해당 품목을 사용하는 모든 모델/변형에 동일하게 적용한다.

## 선택한 방식

생산 가능 수량 서비스 안에 품목 코드 기반 계산 제외 목록을 두고, AF 계산에 전달하는 BOM 그래프에서 `4-PR-0058` 간선만 제거한다. 원본 BOM 캐시와 데이터베이스 레코드는 변경하지 않는다.

## 이유와 대안

1. 선택: 서비스 내부 계산 전용 제외 목록. 현재 한 품목의 명시적 업무 예외에 가장 작고 안전하며 DB 스키마 변경이 없다.
2. 대안: BOM에서 품목을 제거. 실제 조립 BOM이 틀어지므로 요구사항과 맞지 않는다.
3. 대안: 품목별 계산 제외 플래그를 DB에 추가. 앞으로 다수 예외를 관리할 수 있으나, 현재 한 품목 요청에는 마이그레이션·관리 UI가 과하다.

## 검증 기준

- 제외 품목만 부족한 PF 경로는 빠른 생산과 총생산이 다른 필요 품목 재고 한도까지 계산된다.
- PF 재고 기반 출하 대기 값은 기존과 동일하다.
- 제외 품목이 아닌 BOM 부족은 계속 생산 가능 수량을 제한한다.
