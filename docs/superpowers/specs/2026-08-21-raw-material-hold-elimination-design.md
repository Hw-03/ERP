# 원자재 보류 제거 설계

## 목표

사용자가 정리한 7열 검토 시트를 유지하면서 최종 분류가 `보류`인 61개 원자재를 `사출` 또는 `기타`로 재분류한다. DB는 읽기 전용으로만 사용한다.

## 판정 기준

- 구조성 플라스틱으로 판단되는 가이드, 키, 커버, 프레임, 윈도우, 콘 가이드, 블록은 `사출`로 옮긴다.
- LED, LCD 패널, 손잡이·가죽·금속류, USB·WIFI 동글, 방열·팬, 아크릴, 힌지, 스티커·필름, 페라이트·브라켓, 터치펜은 `기타`로 옮긴다.
- 보드·하네스·포장 자재의 명시 신호가 없는 보류 항목을 그 세 분류에 강제로 넣지 않는다.
- 사용자 입력인 검토 메모는 보존하고, 기존 최종 분류가 `보류`인 행만 바꾼다.

## 엑셀 반영

- `원자재 분류 검토`: 사용자가 남긴 7개 열을 유지한다. F열 드롭다운에서 `보류`를 제거하고, 보류였던 행의 E열 근거와 F열 최종 분류를 갱신한다.
- `분류 요약`: 최종 분류 기준으로 사출·보드·하네스·포장 자재·기타 5개를 집계한다. 삭제된 원본 열을 참조해 생긴 판정 상태 영역의 `#REF!` 수식은 제거한다.
- `분류 기준`: 보류 대신 `기타`를 사용한다는 제한 사항과 5개 최종 분류 목록을 반영한다.

## 검증

- 최종 분류 열의 `보류`가 0개인지 확인한다.
- 전체 662개 원자재 수와 5개 최종 분류 합계가 일치하는지 확인한다.
- `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#N/A` 오류가 없는지 확인하고 3개 시트를 렌더링한다.
