# 다크 모드 부서색 가시성 보정

## 목표

다크 모드에서 부서별 막대, 칩, 공정 표시가 서로 구분되도록 하되, 초기 팔레트의 형광감은 되살리지 않는다.

## 결정

- 다크 모드 `departmentDisplayColor()`의 CSS 입력값을 원본 색상 55%와 중성색 `#adb7c3` 45%로 조정한다.
- 라이트 모드는 원본 색상 100%를 유지한다.
- 이 공통 토큰을 사용하는 주간보고, 재고 분포, 재고 목록, 부서 선택 UI가 모두 같은 표시색을 사용한다.
- 재고 부족, 변동, 경고처럼 데이터 상태를 나타내는 의미색은 바꾸지 않는다.

## 검증

- 토큰 계약 테스트가 다크 모드의 55% 설정을 검증한다.
- 최종 프런트엔드 검증 게이트와 3002 로컬 화면 새로고침으로 영향을 확인한다.
