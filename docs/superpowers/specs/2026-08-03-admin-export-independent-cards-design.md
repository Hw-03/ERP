# 관리자 내보내기 독립 카드 설계

## 목적

관리자 내보내기 화면의 `데이터 내보내기`와 `내부 원본 로그 (월별)`을 서로 독립된 작업 카드로 분리해 기능 경계를 명확히 한다.

## 승인된 화면 구성

- 상단의 F704-02·F705-02 공식 서식 카드는 현재 구성을 유지한다.
- 하단은 `xl` 이상에서 50:50 비율의 독립 카드 두 개로 구성한다.
  - 왼쪽: `데이터 내보내기`
  - 오른쪽: `내부 원본 로그 (월별)`
- 두 카드는 같은 행과 같은 가용 높이를 사용한다.
- `xl` 미만에서는 데이터 카드 다음 원본 로그 카드 순서로 적층하고 내보내기 본문이 스크롤한다.

## 데이터 내보내기 카드

- 기존 범위·형식·기간·비활성 데이터 옵션과 다운로드 동작을 유지한다.
- 실행 결과는 다운로드 버튼 바로 위에 표시한다.
- 다운로드 버튼은 선택 범위에 따른 조작부 높이와 관계없이 카드 최하단에 고정한다.

## 내부 원본 로그 카드

- 접기 가능한 `details` 구조를 제거하고 항상 펼친 상태로 표시한다.
- 제목은 관리 작업처럼 보이지 않는 `내부 원본 로그 (월별)`로 표시한다.
- 별도의 `시스템 원본 로그 (월별)` 제목 행은 두지 않는다.
- 월별 파일 목록만 남은 높이를 사용해 세로·가로 스크롤한다.
- 사용자가 데이터 복구를 신경 쓰지 않도록 백필·수동 새로고침 조작은 화면에서 제거한다.
- 백엔드 복구 API는 운영용으로 보존하고 CSV/XLSX 다운로드와 객체 URL 정리는 유지한다.

## 시각 규칙

- 기존 `rounded-[20px]` 표면, `LEGACY_COLORS`/`var(--c-*)`, 18px 제목, 44px 조작 높이를 재사용한다.
- 새로운 색상·그림자·컴포넌트 추상화는 추가하지 않는다.

## 완료 기준

- 하단에 독립된 두 카드가 표시되고 원본 로그는 접기 없이 항상 보인다.
- 모든 범위에서 다운로드 버튼이 데이터 카드 하단 기준선을 유지한다.
- 1923×910에서 바깥 작업 영역이 넘치지 않고 월별 목록만 스크롤한다.
- 1280px 미만에서는 카드가 겹치거나 잘리지 않고 적층된다.
- 관련 Vitest와 프런트엔드 검증 게이트가 통과한다.
