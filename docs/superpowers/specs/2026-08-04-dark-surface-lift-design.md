# 다크 표면 명도 상향 설계

## 목표

다크 모드의 기업형·저채도·무글로우 방향은 유지하면서, 페이지와 카드가 검정에 가깝게 느껴지는 문제를 줄인다.

## 범위

- 다크 테마의 `--background`, `--c-bg`, `--c-s1`~`--c-s4`, `--c-popup-bg`만 딥 슬레이트 계열로 한 단계 밝힌다.
- 의미 전경색, `*Solid` 채움색, 공정색, 텍스트색, 테두리·그림자·glow 정책은 이번 조정에서 유지한다.
- 라이트 모드, API·DB, 부서색 원본 hex, 동결된 주간보고·모바일 탭바는 변경하지 않는다.

## 토큰

| 역할 | 현재 | 적용값 |
|---|---|---|
| 페이지 배경 | `#0d1117` | `#151a21` |
| surface 1 | `#161b22` | `#1b222a` |
| surface 2 | `#1c222a` | `#232c36` |
| surface 3 | `#262e38` | `#2c3743` |
| surface 4 | `#303a46` | `#384553` |
| 팝업 | `#161b22` | `#1b222a` |

surface 간 명도 차이를 유지해 카드·패널·선택 상태의 깊이는 보존한다. 의미색은 새 `--c-bg` 기준으로도 WCAG AA 4.5:1 이상을 테스트로 재검증한다.

## 검증

- 다크 토큰 계약·대비 테스트의 기대값을 새 표면값으로 갱신한다.
- `npm test`, `npm run lint:strict`, `scripts/dev/verify_local.ps1 -Mode frontend`를 실행한다.
- 현재 브랜치의 `http://localhost:3002/mes?tab=dashboard`에서 대시보드·사이드바·카드·팝업의 체감을 확인한다.
