# 설정 모달 설계

## 목적

데스크톱 사이드바의 테마·표시 방식·개인 설정·관리 진입을 하나의 `설정` 버튼과 중앙 모달로 통합한다. 테마와 사이드바 방식은 저장을 눌렀을 때만 적용하며, 개인 설정은 각 행에서 즉시 처리한다.

## 목록형 레이아웃

- 모달 본문은 데스크톱에서 좌우 2열이며, 왼쪽에는 `테마`와 `사이드바 표시 방식`, 오른쪽에는 `개인 설정`과 권한이 있을 때만 `관리`를 표시한다.
- 각 그룹은 내용 높이만 사용하며 배경과 테두리를 두지 않는다. 큰 빈 카드나 중앙 정렬 관리 카드는 사용하지 않는다.
- 데스크톱 두 열은 모달 본문 전체 높이의 얇은 세로선으로만 구분한다.
- 각 그룹은 제목과 그 오른쪽의 가로선으로 구분하고, 설명 문구 없이 바로 목록 행을 표시한다.
- 각 그룹은 위에서부터 이어서 배치하고, 같은 그룹의 목록 행 사이에 12px 여백을 둔다.
- 모든 설정은 작은 아이콘, 제목, 짧은 행 설명, 선택 체크 또는 이동 화살표로 구성한 세로 목록 행으로 표시한다.
- 각 행은 최소 44px 이상의 터치 영역과 버튼 시맨틱을 사용한다.

## 색상과 상호작용

- 기존 사이드바의 의미 색을 설정 모달에도 적용한다.
  - 라이트 테마: 노랑, 다크 테마: 보라
  - 자동 펼침: 청록, 접힘 고정: 파랑, 펼침 고정: 초록
  - PIN 재설정: 보라, 로그인 알림: 노랑, 관리: muted 회색
- 선택된 테마·사이드바 행은 해당 색의 연한 배경과 테두리, 체크 아이콘으로 표시한다. 선택되지 않은 행도 아이콘은 의미 색을 유지한다.
- PIN 재설정은 개별 테두리 카드 없이 행 전체를 눌러 펼친다. 펼쳐진 PIN 입력과 변경 버튼은 같은 목록 영역의 구분선 아래에 표시한다.
- 로그인 알림 토글은 즉시 저장하며, 활성 상태는 노랑으로 표시한다.

## 관리 진입과 닫기

- 관리 행은 관리자 탭이 보이는 사용자에게만 표시하며, 기존 관리자 PIN 진입 콜백을 호출한다.
- 설정 모달은 불투명한 현재 테마 배경을 사용한다.
- 취소, X, 배경 클릭, `Esc`는 저장 중이 아닐 때 임시 테마·사이드바 선택을 버리고 닫는다.

## 검증 기준

- 저장 전 테마와 사이드바 선택은 실제 화면 설정을 바꾸지 않는다.
- 선택 행의 색상과 `aria-pressed` 상태가 일치한다.
- PIN 재설정 행 전체 클릭으로 입력 폼을 열고 닫을 수 있다.
- 관리자 권한, PIN 변경, 로그인 알림, Esc와 저장 중 닫기 방지의 기존 동작을 유지한다.
