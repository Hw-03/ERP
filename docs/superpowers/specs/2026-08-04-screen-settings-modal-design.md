# 설정 모달 설계

## 목적

데스크톱 사이드바 하단의 테마와 표시 방식 제어를 하나의 `설정` 진입점으로 통합한다. 사용자는 중앙 모달에서 변경 사항을 임시로 고른 뒤 `저장`으로 적용한다. 관리 화면 진입도 같은 모달에 넣어, 사이드바는 설정 아이콘 하나만 남긴다.

## 범위

- 데스크톱 사이드바 하단의 기존 테마·표시 방식 제어와 `관리` 탭 버튼을 제거한다.
- 같은 위치에 톱니바퀴 아이콘의 `설정` 버튼을 둔다.
- 생산 가능 수량 상세 팝업과 같은 중앙 오버레이 모달 프레임을 사용한다.
- 모바일 하단 탭 바와 모바일 메뉴는 변경하지 않는다.
- 서버 API, 데이터베이스, 권한 정책은 변경하지 않는다.

## 설정 모달

- 제목은 `설정`으로 표시한다.
- 배경 클릭, X 버튼, `취소`는 저장하지 않고 닫는다.
- `저장`은 테마와 사이드바 표시 방식을 한 번에 적용한다. 적용 중에는 중복 클릭을 막고 `저장 중…`으로 표시한다.
- 적용 실패 시 모달과 사용자가 고른 값은 유지하고 오류를 보여 준다.

### 아이콘 중심 선택 카드

넓은 화면에서는 `테마`, `사이드바 표시 방식`, `관리`의 세 영역을 가로로 배치하고, 좁아지면 세로로 쌓는다. 텍스트는 아이콘의 의미를 보조하는 짧은 제목과 설명으로만 사용한다.

| 영역 | 선택지 | 아이콘 | 동작 |
| --- | --- | --- | --- |
| 테마 | 라이트 테마 | `Sun` | 밝은 테마를 임시 선택 |
| 테마 | 다크 테마 | `Moon` | 어두운 테마를 임시 선택 |
| 사이드바 표시 방식 | 자동 펼침 | `PanelLeftDashed` | 평소 접힘, 마우스를 올리면 펼침 |
| 사이드바 표시 방식 | 접힘 고정 | `PanelLeftClose` | 아이콘만 항상 표시 |
| 사이드바 표시 방식 | 펼침 고정 | `PanelLeftOpen` | 전체 메뉴를 항상 표시 |

- 각 선택지는 큰 아이콘과 짧은 제목을 가진 독립 버튼이다. 한 버튼을 반복해 순환시키지 않는다.
- 선택된 카드의 테두리·배경·아이콘은 청록색으로 강조하고, 선택되지 않은 아이콘은 현재 디자인 토큰의 muted 색을 사용한다.
- 선택된 카드의 오른쪽에는 체크 아이콘을 둔다.
- 기존 토큰과 Lucide 아이콘만 사용하고, 새 아이콘 에셋이나 임의 색상값은 추가하지 않는다.

### 관리 바로가기

- 세 번째 영역은 기존 `Settings2` 아이콘을 중심으로 한 큰 `관리` 실행 카드다.
- 카드 클릭은 저장 여부와 관계없이 즉시 `admin` 화면으로 이동하고, 설정 모달을 닫는다.
- 이 카드에는 선택 상태나 저장 대상이 없다. 기존 사이드바의 `관리` 버튼을 대체한다.
- 접근성을 위해 카드에는 `관리` 이름과 관리 기능을 설명하는 보조 텍스트를 제공한다.
- 현재 로그인 사용자의 `hidden_sidebar_tabs`에서 `admin`이 숨겨진 경우에는 관리 카드를 표시하지 않는다.

### 닫기와 배경

- 모달이 열려 있고 저장 중이 아닐 때 `Esc` 키는 `취소`와 동일하게 임시 변경을 버리고 닫는다.
- 저장 중에는 `Esc`를 무시해 적용 중인 요청을 중단하지 않는다.
- 오버레이 배경은 반투명이 아닌 현재 테마의 불투명 배경 토큰으로 채운다. 따라서 모달 뒤의 화면 내용은 보이지 않는다.

### 톱니바퀴 우클릭

- 설정 버튼을 우클릭한 경우, `admin` 탭이 현재 사용자에게 보이는 경우에만 브라우저 기본 메뉴를 막고 `admin` 탭으로 이동한다.
- 이 이동은 일반 탭 이동 경로를 사용하므로, 관리자 PIN 세션이 아직 없으면 기존 `DesktopPinLock` PIN 입력 화면이 표시된다.
- `admin` 탭이 숨겨진 사용자는 우클릭해도 이동하지 않으며 브라우저의 기본 우클릭 메뉴를 그대로 표시한다.
- 좌클릭은 변함없이 설정 모달을 연다.

## 상태와 데이터 흐름

1. 사용자가 사이드바의 `설정`을 누르면 현재 테마와 사이드바 모드를 임시 상태로 복사해 모달을 연다.
2. 테마·표시 방식 카드는 임시 상태만 바꾼다. 모달을 닫기 전에는 화면과 저장소 값이 변하지 않는다.
3. `저장`은 두 값을 적용하고 기존 사용자 설정 저장 경로를 호출한다.
4. `관리` 카드는 관리 탭이 보이는 사용자에게만 표시하고, 상위 사이드바의 `onTabChange("admin")`를 호출하도록 콜백을 받는다. 모달을 닫은 뒤 관리 화면으로 이동한다.
5. 설정 버튼 우클릭도 같은 탭 전환 콜백을 호출하되, 관리 탭이 숨겨진 사용자에게는 아무 동작도 하지 않는다.
6. `취소`, X, 오버레이 클릭, `Esc`는 임시 상태를 버린다. 단, 저장 중에는 닫기 동작을 막는다.

## 구현 경계

- `AppearanceSettingsModal`은 임시 선택, 저장 요청, 관리 바로가기 클릭만 담당한다.
- `DesktopSidebar`는 모달 열기 상태와 `admin` 탭 전환을 담당한다. `BOTTOM_TABS`의 관리 항목은 제거한다.
- `useAppearancePreferences`는 기존 테마·사이드바 모드 적용과 저장 책임을 유지한다.
- 기존 테마와 사이드바 모드의 실제 동작(`hover`, `collapsed`, `expanded`)은 바꾸지 않는다.

## 검증 기준

- 데스크톱 사이드바에는 설정 버튼만 있고, 기존 테마·표시 방식·관리 버튼은 없다.
- 모달의 모든 선택지에 해당 Lucide 아이콘이 보이며, 선택된 아이콘과 카드가 청록색으로 강조된다.
- 각 테마 및 세 가지 표시 방식은 독립 버튼으로 선택된다.
- `저장` 전에는 실제 화면과 저장소 값이 바뀌지 않고, 저장 후에만 함께 반영된다.
- `관리` 카드를 누르면 모달이 닫히고 `admin` 탭으로 이동한다.
- 관리 탭이 숨겨진 사용자는 관리 카드가 보이지 않고, 톱니바퀴 우클릭도 기본 메뉴 외에는 반응하지 않는다.
- 관리 탭이 보이는 사용자의 톱니바퀴 우클릭은 PIN 입력 화면으로 이동한다.
- 취소·X·오버레이 클릭·`Esc`는 변경을 버린다. 저장 중 `Esc`는 닫지 않는다.
- 모달을 열면 뒤의 화면 내용이 전혀 보이지 않는다.
- 기존 데스크톱 사이드바의 세 표시 방식 동작과 모바일 탐색은 회귀하지 않는다.
