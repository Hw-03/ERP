# 설정 모달 설계

## 목적

데스크톱 사이드바 하단의 테마 전환과 사이드바 표시 방식 전환을 하나의 `설정` 진입점으로 통합한다. 사용자는 큰 중앙 모달에서 두 값을 함께 선택한 뒤 `저장`으로 적용한다.

## 범위

- 데스크톱 사이드바 하단의 기존 테마 버튼과 사이드바 표시 방식 버튼을 제거한다.
- 같은 위치에 톱니바퀴 아이콘의 `설정` 버튼을 둔다.
- 생산 가능수량 상세 팝업과 같은 큰 중앙 모달 프레임을 사용한다.
- 모달에서 테마와 사이드바 표시 방식을 함께 편집하고 저장한다.

모바일 탭 바와 모바일 메뉴는 변경하지 않는다.

## 기존 구현 기준

- `DesktopSidebar.tsx`는 하단에 `ThemeToggle`과 `SidebarModeToggle`을 직접 렌더한다.
- `ThemeToggle.tsx`는 현재 테마를 즉시 DOM, 로컬 저장소, 로그인 사용자 설정에 반영한다.
- `SidebarModeToggle.tsx`의 `useSidebarMode`는 현재 사이드바 모드를 불러오고, 순환 전환과 저장을 담당한다.
- `CapacityDetailModal.tsx`는 큰 중앙 모달의 기존 프레임 패턴이다.

## UI 설계

### 진입 버튼

- 라벨: `설정`
- 아이콘: 톱니바퀴
- 위치: 데스크톱 사이드바 하단의 기존 두 제어가 있던 자리
- 접힌 사이드바에서는 아이콘과 접근 가능한 라벨을 제공하고, 펼친 사이드바에서는 라벨과 보조 설명을 함께 표시한다.

### 모달

- 제목: `설정`
- 생산 가능수량 상세와 동일한 종류의 큰 중앙 모달 프레임: 어두운 오버레이, 둥근 큰 카드, 닫기 버튼, 넉넉한 헤더와 하단 조작 영역.
- 바깥 클릭 또는 X 버튼은 저장하지 않고 닫는다.
- 하단 버튼: `취소`, `저장`.

### 설정 카드

큰 카드 두 개를 한 화면에 배치한다.

1. `테마`
   - `라이트`, `다크` 두 선택 버튼.
   - 현재 임시 선택값을 명확히 강조한다.
2. `사이드바 표시 방식`
   - `자동 펼침`: 평소 접혀 있으며 마우스를 올리면 펼쳐짐.
   - `접힘 고정`: 항상 아이콘만 표시.
   - `펼침 고정`: 항상 전체 메뉴 표시.
   - 세 개의 독립된 선택 버튼으로 표시하며, 기존처럼 한 버튼을 반복 눌러 순환하지 않는다.

## 상태와 저장 흐름

1. 사용자가 `설정`을 누르면 현재 적용된 테마와 사이드바 모드를 임시 상태로 복사하고 모달을 연다.
2. 모달 안의 선택 버튼은 임시 상태만 변경한다. 배경 화면과 영구 저장값은 변경하지 않는다.
3. `취소`, X, 오버레이 클릭은 임시 상태를 버리고 모달을 닫는다.
4. `저장`은 테마와 사이드바 모드를 함께 적용하고 각 기존 사용자 설정 저장 경로를 호출한다.
5. 저장 중에는 중복 저장을 막고 버튼을 `저장 중…`으로 표시한다.
6. 저장에 실패하면 모달을 유지하고 오류를 알린다. 사용자는 값을 유지한 채 다시 저장하거나 취소할 수 있다.

## 구현 경계

- 현재 테마 적용 및 저장 로직은 재사용 가능한 함수/훅으로 분리해 모달의 저장 동작이 사용한다.
- 사이드바 모드 로드·저장 로직은 `useSidebarMode`를 유지하되, 순환 전환 UI는 제거한다. 모달이 특정 모드를 저장할 수 있는 명시적 setter를 제공한다.
- 새 모달 컴포넌트는 프레젠테이션과 임시 선택 상태를 담당한다. 사이드바는 열림 상태와 현재 설정값의 적용만 담당한다.
- 새로운 백엔드 API나 데이터베이스 변경은 필요 없다.

## 검증

- 사이드바에는 `설정` 진입 버튼만 남고 기존 두 제어는 렌더되지 않는다.
- 모달을 열면 현재 테마와 표시 방식이 선택된 상태로 나타난다.
- 테마/사이드바 선택을 바꾼 후 취소하면 화면과 저장값이 변하지 않는다.
- 저장하면 두 값이 함께 적용되고, 로그인 사용자와 비로그인 로컬 저장소 경로 모두에서 다음 진입 시 복원된다.
- 저장 중 중복 클릭이 막히며, 저장 실패 때 모달과 선택값이 유지되고 오류가 보인다.
- 기존 데스크톱 사이드바의 `hover`, `collapsed`, `expanded` 동작은 각각 동일하게 유지된다.
