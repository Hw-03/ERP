# 설정 모달 설계

## 목적

데스크톱 사이드바의 테마·표시 방식·관리 진입을 하나의 `설정` 버튼과 중앙 모달로 통합한다. 변경은 `저장`을 눌렀을 때만 적용한다.

## 설정 모달

- 생산 가능 수량 상세와 같은 큰 중앙 모달을 사용한다.
- 오버레이는 현재 테마의 불투명 배경으로 채워 모달 뒤 화면을 보이지 않게 한다.
- `취소`, X, 배경 클릭, `Esc`는 임시 선택을 버리고 닫는다. 저장 중에는 닫기 동작을 막는다.
- 테마와 사이드바 표시 방식은 각각 독립 카드로 선택한다.
- 카드에는 아이콘을 앞에 배치한다: `Sun`, `Moon`, `PanelLeftDashed`, `PanelLeftClose`, `PanelLeftOpen`.
- 선택된 카드·아이콘·체크는 청록색, 선택되지 않은 아이콘은 muted 토큰으로 표시한다.
- 저장 성공 후에만 테마와 사이드바 모드를 직원 설정과 로컬 상태에 함께 반영한다.

## 관리 진입

- 관리자 탭이 현재 사용자에게 보이는 경우에만 모달에 `Settings2` 아이콘 중심의 `관리` 카드를 표시한다.
- 기존 사이드바 하단의 `관리` 버튼은 제거하고 설정 버튼만 남긴다.
- 설정 버튼 우클릭은 관리자 탭이 보이는 사용자에게만 기본 메뉴를 막고 관리자 PIN 입력 화면으로 이동한다.
- 관리자 탭이 숨겨진 사용자는 관리 카드를 보지 못하고, 우클릭해도 브라우저 기본 메뉴가 유지된다.
- 관리 카드와 우클릭은 같은 재인증 경로를 사용한다. 이미 관리자 화면이 열려 있어도 화면을 다시 마운트해 새 PIN 입력부터 시작한다.

## 상태와 구현 경계

- `AppearanceSettingsModal`은 임시 선택, 저장 요청, 관리 진입 요청을 맡는다.
- `DesktopSidebar`는 설정 열기와 `visibleTabs.includes("admin")` 권한 판단을 맡는다.
- `DesktopMesShell`은 dirty-navigation 가드를 거친 관리자 탭 전환과 PIN 진입 nonce를 맡는다.
- 기존 직원별 `sidebar_mode` 저장 API와 테마 저장 경로를 그대로 사용한다. 모바일 탐색과 서버 API·DB는 변경하지 않는다.

## 검증 기준

- 저장 전 실제 테마·사이드바 상태는 바뀌지 않는다.
- `Esc`와 불투명 배경이 동작한다.
- 관리자 노출 사용자만 관리 카드와 우클릭 PIN 진입을 사용할 수 있다.
- 관리자 탭이 활성화된 상태에서도 PIN 진입 요청은 새 PIN 화면을 표시한다.
