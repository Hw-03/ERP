# 품목코드 표시 정렬 통일

## 목표

품목 관리에서 모델 선택 칩과 품목코드 미리보기를 실제 품목코드 부여 규칙과 같은 제품기호 오름차순으로 표시한다.

## 범위

- 프런트엔드 공용 유틸리티가 모델 슬롯을 제품기호로 변환하고 기호 오름차순으로 정렬한다.
- 품목 관리 폼의 모델 칩과 코드 미리보기가 이 유틸리티를 함께 사용한다.
- 백엔드의 저장 규칙과 기존 DB 품목코드는 변경하지 않는다.

## 동작

선택 슬롯, 화면 표시 순서, 사용자의 클릭 순서와 무관하게 실제 제품기호를 기준으로 정렬한다. 예를 들어 기호 `3`, `8`, `4`가 선택되면 모델 칩은 `3`, `4`, `8` 순으로 표시되고, 공정 `AR`, 일련번호 `0723`의 미리보기는 `348-AR-0723`이다.

## 검증

슬롯 순서와 기호 순서가 다른 테스트 데이터를 사용해 모델 칩 순서와 코드 미리보기가 모두 기호 오름차순임을 검증한다.
