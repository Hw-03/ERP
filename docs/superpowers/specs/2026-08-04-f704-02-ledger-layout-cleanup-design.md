# F704-02 자재 입출고관리대장 양식 정리 설계

## 목적

다운로드되는 `F704-02 (R01) YYYY년 자재 입출고관리대장`에서 사용하지 않는 모델명·규격 열과 본문에 남아 있는 노란 채우기를 제거한다. 품목명 길이 처리 방식은 이번 범위에서 변경하지 않는다.

## 확정 범위

- 원본 템플릿의 `양식`, `양식_출력용` 두 시트에서 기존 E열(모델명)과 G열(규격)을 물리적으로 삭제한다.
- 최종 열 순서는 `No`, `날짜`, `발주번호`, `품번`, `품명`, `수량`, `입고/출고`, `입/출고처`, `담당자`, `검수`, `비고`로 한다.
- 본문 4행부터 모든 데이터 셀의 채우기를 제거한다. 제목 행의 채우기·테두리·날짜 및 수량 표시 형식은 유지한다.
- 생성기는 새 열 위치로 값을 기록하며 모델명 조회와 규격 빈칸 기록을 제거한다.
- 품목명 열의 너비, 줄바꿈, 글자 크기, 행 높이는 변경하지 않는다.

## 구현 경계

- `backend/app/assets/f704_02_template.xlsx`의 두 시트에 열 삭제 및 본문 서식 변경을 적용한다.
- `backend/app/services/f704_02_ledger.py`의 데이터 구조, 조회, 셀 매핑, 자동필터·시트 범위를 11열 양식에 맞춘다.
- 관련 단위·라우터 테스트는 새 열 위치와 노란 본문 채우기 제거를 검증한다.
- 다운로드 API, 파일명, 거래 선별 기준, 제목 행의 색상은 변경하지 않는다.

## 검증 기준

- 생성된 워크북의 두 시트는 11열 양식이며 헤더와 데이터 위치가 동일하다.
- 모델명과 규격 값은 생성되지 않으며, 품명은 E열·수량은 F열에 기록된다.
- 기존 58번 거래 행 위치를 포함해 본문 셀에 노란 채우기가 없다.
- 제목 행의 배경색, 테두리, 날짜·수량 표시 형식과 다운로드 API 회귀 테스트가 유지된다.
