## 집계/API — GPT-6.1 Sol · High · 병렬 가능

- 기존 worker_items 품목 수·참여자·정렬을 유지하고 각 행에 선택적 quantities_by_unit 배열을 추가한다. 각 항목은 unit과 surveyed/confirmed/applied(number 또는 null)를 제공한다.
- 조사량은 작업자×품목×위치의 마지막 실제 저장값(정상·불량·B급·구형 합계)을 사용한다. 새 시도의 전부 null은 이전 저장값을 대체하지 않는다. 부분 입력은 저장된 분류만 더하고 명시적0은 유효하다. 중단·작업자 교체 전 저장량도 해당 작업자의 조사 실적에 남긴다.
- 확인/반영은 현재 유효한 entries와 종료 회차의 봉인 증빙을 사용한다. 종료 시 선택 반영을 포함한다. 미상 증빙은 null이며 실제0과 구별한다.
- EA/개를 EA로 통합하고 다른 단위는 분리한다. 기존 회차 일괄 조회를 확장하며 N+1·스키마·권한 변경은 하지 않는다.

## 화면 — GPT-6.1 Sol · High · 병렬 가능

- 품목 수/실셈 수량의44px 전환을 제목 옆에 배치하고 좁으면 줄바꿈한다. 기본은 품목 수이며 갱신·회차 변경 중 선택을 유지한다. 순서는 기존 품목 수 정렬이며 전환 때문에 움직이지 않는다.
- 숫자는 쉼표를 포함한 정확한 값, null은—. 같은 단위의 모든 작업자·확인/반영에 같은 막대 최대값을 사용한다. 자료가 없는 이전 API는 수량 전환을 비활성화하고 안내한다.
- PC 숫자 영역은 최장 숫자에 맞춰확인/반영공통폭을 확보한다. 숫자폭/막대는200ms로 전환하고 reduced-motion은 즉시 전환한다. 막대가32px보다 작으면 전부 숨긴다. 카드폭·이름120px를 유지한다. 극단값에서 숫자2개조차 들어가지 않으면 stage라벨+수량2줄로 전환한다.
- 모바일품목수는 기존표에서조사열을제거한다. 수량은 이름한줄+확인/반영수량2열, 부족하면 라벨+수량2줄. 축약·잘림·작은폰트로 피하지 않는다. 복수단위는 개별표시한다. 최근활동의 펼침상태를 유지한다.
