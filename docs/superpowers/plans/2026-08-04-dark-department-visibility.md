# 다크 모드 부서색 가시성 보정 실행 계획

> **추천 모델: GPT-5.6 Terra** - 공통 색상 토큰이 주간보고와 재고 화면에 함께 적용되므로 일관성 검토가 필요하다.
> **추천 추론 수준: 높음** - 상태색과 부서 식별색을 분리한 채 전체 화면 영향을 확인해야 한다.
> **실행 형태: 단독** - 단일 공통 CSS 토큰과 계약 테스트만 변경한다.

**GOAL:** 다크 모드 부서 표시색의 원색 비중을 55%로 올려, 주간보고와 재고 화면에서 부서 구분을 선명하게 유지한다.

## 작업

1. `frontend/lib/__tests__/dark-theme-tokens.test.ts`의 부서 표시 토큰 기대값을 55%로 변경하고, 대상 테스트가 현재 30% 설정 때문에 실패하는지 확인한다.
2. `frontend/app/globals.css`의 다크 모드 `--c-department-color-source-weight`를 55%로 바꾸고, `_attic/docs/mobile-design-system.md`의 표시 변환 계약을 55%/45%로 갱신한다.
3. 대상 테스트와 `scripts/dev/verify_local.ps1 -Mode frontend`를 실행하고, 3002의 주간보고·대시보드에서 부서색이 상태색과 혼동되지 않는지 확인한다.

## 범위 제외

- 부서 DB 원본 색상과 라이트 모드는 변경하지 않는다.
- 경고·부족·변동 상태의 의미색과 동결된 화면 구조는 변경하지 않는다.
- 커밋과 푸시는 수행하지 않는다.
