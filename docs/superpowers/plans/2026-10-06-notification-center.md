# DEXCOWIN MES 알림 통합 개선

**GOAL:** 로그인 알림과 종 버튼 알림을 하나의 중앙 팝업으로 통합하고, 기존·신규 알림의 업무 정보를 읽기 쉽게 표시한다.

## 승인된 구현 기준

- 로그인 시 안 읽음, 종 버튼 클릭 시 전체 탭으로 같은 중앙 팝업을 연다.
- 최대 너비 640px, 모서리 24px, 화면 높이 제한, 목록만 스크롤한다.
- 헤더 제목·미읽음 수·닫기, 전체/안 읽음 탭·모두 읽음, 하단 로그인 팝업 설정·읽은 알림 삭제를 제공한다.
- 제목과 종 아이콘을 같은 높이로 정렬하고, 요청자는 오른쪽 위에 표시한다. 본문 14px 이상·조작 영역 44px 이상을 적용한다.
- 배경 클릭·Esc·포커스 유지/복귀를 지원한다. 모두 읽음 후 창과 선택 탭을 유지한다.
- 신규 본문은 앞 3개 라인의 품목별 수량, 추가 라인 외 N건, 여러 라인의 전체 수량을 표시한다. 인수인계는 작성자·부서 경로·제목을 유지한다.
- 과거 요청번호 형식은 연결 요청·품목 정보와 원문이 정확히 일치할 때만 display_body로 보완한다. DB와 응답의 body는 원문 그대로 유지한다. 데스크톱 카드에는 요청번호 보조 줄을 표시하지 않는다.
- GET unread_only=false 옵션을 추가한다. 필터는 조회 제한 전 적용하며 unread_count는 전체 미읽음 수다.
- 직원별 전체·미읽음 캐시를 분리하고 저장 성공 시 조회 취소·캐시 반영·재조회 순서로 처리한다.
- 최초 로딩·실패·재시도·기존 목록 유지·읽음/삭제/설정 실패를 팝업 안에 표시한다.
- 로그인당 1회 표시·직원 설정·수신자/이동 권한은 유지한다. 모바일은 현재 배치와 열기 방식을 유지하고 개선된 본문만 표시한다.
- DB 구조 변경·과거 본문 재작성·자동 커밋/푸시는 수행하지 않는다.

## 2026-10-06 화면 피드백 반영

- 카드 제목은 입출고 내역의 업무명, 품목은 대표 스냅샷명과 `외 N품목` 형식으로 표시한다.
- 작성자를 제목 오른쪽으로 옮기고 중복 작업 문구와 수량 상세 줄을 제거한다. 결재 요청·승인·반려 구분은 작은 배지로 유지한다.
- 실행 전 대기 요청에는 거래 이력이 없으므로 검증된 요청·배치 정보로 업무명과 고유 품목 수를 요약한다. 미확인 연결 정보는 기존 본문으로 fallback한다.
- 모바일 본문과 서버 저장 본문은 기존 승인 기준을 유지한다.

### 추가 간격 피드백

- 제목·품목 사이 여백을 12px에서 4px로 줄이고, KST 날짜는 제목 줄 오른쪽의 요청자 앞에 배치했다.
- 헤더의 중복 숫자 배지를 제거하고 미읽음 안내를 오른쪽으로 옮겼다. 알림 제목은 기존 20px를 유지하며 아이콘과 세로 가운데로 정렬했다.
- NotificationDialog 테스트 13개, 해당 파일 ESLint와 diff 공백 검사 통과. 실제 브라우저에서 배치·간격·제목 크기를 확인했다.
