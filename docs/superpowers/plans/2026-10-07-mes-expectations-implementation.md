원본 기대값과 사용자 피드백은 SHA256과 함께 보존한다. 후속 원장에서 기존 ID·원래 기대·사용자 의견·최종 기대·결정·개별 검증 조건을 연결한다. ID 주석이나 과거 관찰을 현재 PASS로 취급하지 않는다. 기본 계약과 추가 기대값의 분모는 원본에서 계산한다.

신규 revision은 직원 `level`만 삭제한다. SQLite native DROP과 PostgreSQL 컬럼/미사용 enum 제거를 사용한다. 기존 마이그레이션은 보존한다. 보존 검사에서 직원 테이블을 통째로 제외하지 않고 컬럼 projection과 행 내용·연결을 비교한다.

DB는 복제본에서 검증한다. 원본 개발 DB나 직원 환경에 자동 적용하지 않는다. 고정 주간보고·모바일 내비게이션 디자인·출하 카드, 제외 기능, 다른 세션 변경을 보존한다. 브랜치 변경·커밋·푸시·직원 배포는 실행 범위에 포함하지 않는다.

반복 개발은 관련 검사만 실행한다. 공통 직원 계약과 DB 보존 검사 변경 때문에 최종 통합 검증은 한 번 수행하고, 후속 수정은 영향을 받은 검사만 재실행한다. 실행 로그와 원장 연결 상태를 별도 보고한다.
