# 전수조사 통합 및 원본 워크트리 정리 준비

**GOAL:** 최신 main에 전수조사와 필수 의존성을 통합·검증하고, 원본 워크트리를 정리해도 필요한 코드·데이터·기록이 보존되는 상태를 만든다.

## 작업 기준

`C:/ERP`의 현재 main에 미커밋 변경으로 통합한다. 메인 개발 서버만 중지하고 직원 서버·기존 QA·실제 DB·원본 워크트리를 보존한다. 검증은 외부 복사 DB에 한정한다. 커밋·푸시·배포·실제 정리는 포함하지 않는다.

## 통합

모든 수정·미추적 파일을 전수 대조하여 통합·기반영·별도 보존으로 분류한다. 조사·확인·반영·진행·회차·증빙·복구·메뉴 설정과 필수 세션·POOL·예약·취소 연동을 이식한다. 기존 공통 파일은 최신 main 기준으로 결합한다. 관련 없는 UI 변경은 보관하고 메인에는 적용하지 않는다.

직원 level을 복원하지 않는다. 회차 관리는 부서 정·부, 강제 해제·업무 정정 및 복구는 부서 정·부 + 매 요청 관리자 PIN으로 통일한다. 일괄 표시는 참여 부서 활성 직원의 실제 개인 설정을 수정하고 부서 정·부는 제외한다. 기존 로그인·감사·직원 설정·저장 보호를 유지한다.

기존 두 마이그레이션 체인은 보존하고 병합 revision으로 단일 head를 만든다. 메인/QA DB 복사본을 각각 업그레이드하여 기존 업무·조사 데이터와 증빙 보존을 검증한다.

## 검증과 완료

관련 회귀 검사부터 수행한 뒤 최종 SQLite backend·frontend 검사, TypeScript·lint·production build·OpenAPI·bundle 검사를 실행한다. 격리 브라우저에서 PC·모바일과 실패·복구·대량 반영·메인 기존 업무를 검증한다. PostgreSQL 실환경 미검증은 별도로 남긴다.

원본 ignored 자료까지 필요한 내용은 외부 보관하고 해시를 대조한다. 모든 원본 변경에 판정과 근거를 남기고 원본 경로 없이 메인 코드가 실행되는지 확인한다. 결과와 정리 가능 판정은 활성 인수인계에 기록한다. 실제 DB 스키마 적용 전 원본 DB에 연결하는 메인 서버는 중지 상태로 남긴다.
