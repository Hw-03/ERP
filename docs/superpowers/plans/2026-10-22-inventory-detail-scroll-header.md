# 재고 상세 패널 스크롤 헤더 — 완료 (2026-10-22)

**GOAL:** 데스크톱 재고 상세 패널에서 스크롤하면 부가 정보가 사라지고 품목명만 상단에 남아 본문을 더 넓게 보여준다.

## 적용 결과

- 재고 상세의 세 탭에만 접히는 헤더를 적용했다. 공통 패널의 `collapsibleHeader` 기본값은 false이며 다른 업무 패널과 모바일은 기존 구조를 유지한다.
- 탭·품목 코드·상태·복사는 본문과 함께 스크롤되고, 실제 영역 높이에 맞춰 흐려진다. 품목명은 기존 22px·최대 두 줄로 상단에 고정한다.
- 닫기와 하단 입고·출고 버튼은 계속 표시한다. 고정 제목은 불투명하게 합성한 패널 배경으로 본문 글자가 비치지 않게 한다.
- 상단으로 돌아오면 헤더를 복원한다. 탭 전환·품목 변경·재열기는 맨 위에서 시작하며 미저장 입력은 다시 마운트하지 않는다. 헤더 제어 요소로 키보드 포커스가 이동해도 상단을 복원한다.
- 최근 내역의 불필요한 전체 높이 지정을 제거했다. 짧은 내용에는 접힘을 위한 여백을 추가하지 않는다.

## 후속 수정 — 스크롤 중 카드 모서리 유지 (2026-10-22)

- 출하 화면의 외부 스크롤 프레임처럼, 현재 보이는 카드의 위·아래 절단 경계에 둥근 마스크와 테두리를 표시한다. 반경은 해당 카드에서 읽고 기존 배경·테두리 색상 토큰을 유지한다.
- 수량 현황·위치별 재고·관련 작업·이미지·공급처 카드에 적용한다. 카드 사이 빈 공간에서는 프레임을 숨기며, 장식은 클릭·키보드 입력을 가로채지 않는다.
- 헤더가 접히는 데스크톱 패널에서만 동작한다. 높이를 바꾸거나 중첩 스크롤을 추가하지 않으며 모바일의 표시와 스크롤은 유지한다.
- 경계 반경·위치와 빈 공간에서의 숨김 회귀 테스트를 추가하고 관련 5개 테스트 파일 114개, 변경 파일 ESLint, 타입 검사를 통과했다. 실제 3120 화면과 DB 없는 라이트·다크 화면에서 확인했다.
- 사용자가 지목한 선은 제목 양옆으로 비치던 카드 경계였다. 잘못 제거한 둥근 카드 테두리는 복원하고, 제목 배경을 스크롤 영역 밖의 패널 안쪽 폭까지 덮어 양옆의 비침을 가리도록 수정했다. 이때 네이티브 스크롤바 영역은 덮지 않는다.
- 제목 배경의 외부 폭·스크롤 위치 추적 회귀 테스트를 추가했다. 패널 관련 30개 테스트, ESLint, 타입 검사를 통과했고 실제 화면의 양옆 지점에서 수정 전후 픽셀을 비교해 선이 사라졌음을 확인했다. 기록: `title-side-lines-before.png`, `title-side-lines-fixed.png` (앞서 명시한 로컬 검증 자료 폴더).
- 스크롤바 가림을 피하려고 제목 배경의 폭을 제한했던 임시 처리는 아래 외부 레일 구조로 대체했다. 당시 검증 기록: `scrollbar-uncovered-expanded.png`.
