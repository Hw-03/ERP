# 대시보드 관련 작업 카드 정리

**GOAL:** 선택 품목의 재고 변화를 빠르게 비교하고 필요한 구성품만 펼쳐 본다.

## 완료 — 2026-10-22

- 담당자·부서·작업 종류와 진행 상태, 선택 품목명, 위치·방향·예정 수량 순으로 표시한다. 후속 요청에 따라 작업 종류는 담당자·부서 옆으로 옮기고 별도 줄은 제거했다. 각 작업 요약의 수량 위에 선택 품목명을 한 번 표시하고 코드는 반복하지 않는다.
- 다른 작업 대상은 첫 품목·수량과 `외 N건`으로 요약하고 나머지를 상세에 둔다. 추가 효과는 품목별로 묶되 위치·방향·단위를 합산하거나 상쇄하지 않는다.
- 선택 품목의 효과가 없고 예약만 있으면 위치별 `사용 예약`으로 표시한다. 경고는 접힌 상태에서도 보인다.
- 단순 작업은 펼침을 생략한다. 복합 작업 한 건만 있으면 처음 자동으로 열고 여러 건은 한 건씩 연다. 수동 접힘은 재조회 후 유지하며 품목 변경 시 초기화한다.
- 바깥 둥근 카드와 배경은 유지하고 내부 카드 테두리를 구분선으로 바꿨다. 바깥 패딩 16px, 작업 패딩 12px, 본문 14px·보조 12px을 사용한다.
- `마지막 저장`과 `완료 시 재고 변동` 문구를 제거했다. 이 문서의 표시 규칙은 `2026-10-22-inventory-detail-cards.md`에 남은 이전 관련 작업 표시 이력을 대체한다.
- 공유 표시 컴포넌트를 PC·모바일에 적용했다. 수량 현황·위치별 재고·패널 제목·스크롤바·하단 동작과 API·DB·공개 타입·입출고 표는 이번 변경 대상에서 제외했다.
