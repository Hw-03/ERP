# 모바일 출하 전체 디자인 재구성

**추천 모델: GPT-6 Sol** — 기존 모바일 디자인을 출하 전체 화면에 적용한다.
**추천 추론 수준: High** — 시트와 접기 구조를 바꾸면서 초안·이탈 보호를 유지한다.
**실행 방식: 하위 에이전트 병렬 작업** — 작성·상세를 분담하고 부모가 공통 표현·목록·이력·검증을 통합한다.

## 승인 범위

- 기존 모바일 토큰, 20px 카드, 본문 여백 12px, 카드 내부 16px, 44px 터치 영역을 사용한다.
- 허브·관리·이력과 작성 1~5단계, 상태별 상세, 검색·추가 시트·확인창을 일관되게 구성한다.
- 작성은 공통 진행 헤더·고정 작업 버튼을 사용하고, PF 검색은 BottomSheet, BOM은 접기 섹션으로 바꾼다.
- 상세는 요약·인보이스/SN·부족 재고·준비 체크를 먼저 표시하고 보조 정보와 이력은 접는다.
- 긴 품명은 두 줄과 별도 펼침 버튼을 사용한다. 수량은 줄바꿈하지 않는다.
- 기존 API·초안·URL·이탈 보호 계약과 PC·동결된 하단 탭바를 유지한다.
- 커밋·푸시는 별도 요청 시 진행한다.

## 검증

관련 Vitest, TypeScript, 변경 파일 ESLint 및 격리 QA DB 브라우저 검증을 수행한다.
브라우저 결과와 실행 환경·소스 해시는 `_attic/runtime/mes-browser-regression/`의 해당 실행 기록에 남긴다.

## 구현 및 검증 완료 — 2026-10-07

공통 출하 헤더·상태·품명 펼침·접기 영역과 허브·관리·이력·작성·상세를 적용했다.
실제 브라우저에서 작성 폭과 상세 카드 축소 문제를 수정했다.
기본 구성품 수량 변경도 최종 변경 요약에 표시한다.
