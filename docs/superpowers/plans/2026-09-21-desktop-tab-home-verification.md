# PC 동일 탭 첫 화면 복귀 검증

검증일: 2026-09-21. 대상: 로컬 개발 서버 3001, PC, 관리자 계정.
업무 저장·제출·승인·재고 반영은 실행하지 않았다. 임시 검증 입력은 저장하지 않고 폐기했다.

## 구현 기준

- 같은 탭 클릭은 화면 소유자의 복귀 동작을 호출한다. 화면 전체 재마운트를 하지 않는다.
- 이미 첫 화면이면 작성 내용·검색·필터·날짜를 유지하고 경고와 복귀 모션을 실행하지 않는다.
- 하위 화면의 미저장 내용은 기존 dirty-guard로 보호한다. 저장 기능 없는 업무는 나가기/계속 머무르기만 제공한다.
- 저장·실행 중에는 복귀를 차단한다. 저장 실패 시 머무르고, 저장 완료 상태가 반영된 뒤 이동한다.
- 복귀 모션은 본문 opacity 0.7→1, 180ms ease-out 한 번이다. reduced-motion에서는 생략한다.
- PC 입출고 단계와 출하 첫 메뉴 URL은 즉시 기록한다. 늦은 단계 스냅샷과 초안 조회가 복귀를 되돌리지 않도록 한다.
- 주간보고는 BOM 상세 닫기 등록만 추가했다. 모바일 하단 탭 바와 출하 최종 카드 크기는 변경하지 않았다.

## 자동 검증과 한계

- 실제 DirtyGuardProvider를 사용한 셸·복귀 계약 테스트: 첫 화면 무동작, 중복 클릭, 취소, 폐기, 저장 실패·성공 후 이동, 등록 해제·최신 상태, 단일 모션·history 기록.
- 출하 작성 1~5단계, 품목 전환 2~4단계는 매개변수화된 fixture로 경고 취소·폐기와 업무 API 미실행을 확인한다.
- 지도 상세·저장 중 복귀 차단, 일보 실제 내부 상세 닫기, 검색 자동 펼침 접기, 불량 조회 조건 보존, 입출고 URL 지연 경합 회귀 테스트를 포함한다.
- 실제 저장 성공·실패는 모의 API 테스트로만 검증했다. 브라우저에서는 저장·승인·재고 변경을 실행하지 않았다.
- 관리자 내 요청·저장 초안·AS·연구 승인함은 데이터가 없어 개별 상세를 브라우저로 열지 않았다. 기존 목록·복원 테스트로 보완한다.
- 품목 전환 최종 단계는 실제 재고 조건으로 브라우저 진행을 제한하고 실행 가능한 fixture로 검증했다.
- 모든 품목·권한 조합, 입출고 모든 작업 유형의 모든 최종 단계, 출하 준비의 모든 상태, 불량 처리의 모든 업무 조합을 브라우저 통과로 주장하지 않는다. 공통 복귀 경로 및 위 표의 실제 확인 경로와 자동 검증을 구분한다.
- 사이드바를 가리는 모달은 기존 닫기·취소를 사용한다. 배경 클릭 차단을 해제하지 않았다.

## 최종 자동 검증 결과

- `verify_local.ps1 -Mode smart -ChangeSet staged`: 최종 통과. 프론트엔드 파일만 별도 임시 인덱스에 담아 검사했으며 실제 인덱스는 변경하지 않았다. 임시 인덱스 제거 확인.
- changed-file ESLint 및 incremental TypeScript 검사 통과.
- 연관 Vitest: 75개 파일, 998개 테스트 통과.
- 직접 변경 Vitest: 12개 파일, 368개 테스트 통과. 연관 테스트와 겹치는 수치이므로 합산하지 않는다.
- `git diff --check` 통과.
- 첫 스마트 실행의 연관 테스트 실패는 재실행에서 재현되지 않았고, 최종 스마트 실행의 모든 게이트가 통과했다. 출하 등의 테스트에서 기존 React `act(...)` 경고는 출력된다.
- 백엔드·운영 스크립트·기존 검토 문서의 무관 변경은 보존했다. 커밋·푸시하지 않았다.

## 2026-09-22 출하·불량 복귀 모션 보정

- 기존 모션은 실행되지만 70% 불투명도에서 시작해 큰 메뉴 카드가 즉시 나타나는 인상을 주었다. 불량 복귀 직후 브라우저 측정값은 약 0.825였다.
- 출하·불량에 한해 200ms ease-out, opacity 0→1로 조정했다. 다른 탭의 180ms 0.7→1 효과, reduced-motion 처리, 미저장 보호는 유지한다.
- 김현우 계정의 실제 출하 요청 상세(페루 기본 White)와 격리 목록에서 사이드바 복귀를 검증했다. 중간 프레임 opacity는 각각 약 0.591, 0.378로 확인했고, 첫 메뉴 연타 후에는 1을 유지했다.
- 본문 좌표 x=96, y=98, 크기 1813×798은 복귀 및 연타 후 동일했다. 업무 데이터 저장은 하지 않았다.
- 셸 및 복귀 컨트롤 테스트 58개 통과, 변경 두 파일 ESLint 및 git diff --check 통과. 이번 좁은 모션 보정에는 전체 스마트 검증을 재실행하지 않았다.
