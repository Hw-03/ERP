# 재고 상세의 기존 카드형 디자인 복원

**GOAL:** 첨부한 기존 화면의 카드 구성을 복원하고, 예약·입고 예정 정보를 같은 디자인 안에 자연스럽게 배치한다.

## 승인된 구현

- 수량 현황은 옅은 배경 카드 안에 사용 가능 재고·예약 재고·입고 예정의 같은 크기 카드 세 개를 둔다.
- PC 외곽은 모서리 28px·여백 20px, 내부는 모서리 18px·흰 표면·얇은 테두리를 사용한다. 모바일은 같은 구성에서 여백과 간격만 줄인다.
- 라벨 12px, 숫자 20px로 통일한다. 사용 가능 수량에 기존 재고 상태색을 적용하고 예약·예정은 일반 정보색을 사용한다.
- 예약 카드를 누르면 아래 전체 너비에 작업·승인·출하 예약을 펼친다. 입고 예정은 양수일 때만 ‘완료 후 사용’을 카드 아래에 표시한다.
- 위치별 재고는 옅은 외곽과 흰 부서 행 카드를 복원한다. 예약 보조 정보와 음수 가용량, 불량·B급·구형 분류 및 이동 동작을 유지한다.
- 불량 행은 기존 붉은 테두리·옅은 배경·텍스트로 강조한다. 관련 작업도 같은 외곽 카드로 묶되 빈 상태는 한 줄로 유지한다.
- 현재 공급처·관리 재고와 제목·탭·빠른 작업 버튼, 목록의 예약 사선은 유지한다.
- 작업 현황과 위치별 재고의 표시만 수정하며 API·타입·계산·DB·브랜치·커밋·푸시는 변경하지 않는다.
