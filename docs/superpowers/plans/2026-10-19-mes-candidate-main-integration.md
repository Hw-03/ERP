사용자 승인: 후보만 병합·커밋·푸시·CI 확인. 후보 3038/8038은 소유권 확인 후 중지하고 통합판으로 복원. main·직원·예약 변경 금지. 과거 BOM/AS 원인 추적 반복 중단, 미확정 유지.

## 통합 계약

- 권한: main 로그인·권한 저장 버전 가드에 후보 focus 갱신을 연결. 늦은 조회가 저장 결과를 덮지 않음. 창고/생산부 정·부 결재 분리 및 자동 승인 유지.
- 화면 회수: main 진행 중 입력 보존과 후보 복구/뒤로가기 보호 함께 유지.
- 관리자 BOM: main 조회 상태/늦은 응답 방어와 후보 초안·원자적 구성 저장·취소 보호 함께 유지.
- 불량: main 최초 발생 분류 통계/UI와 후보 복귀 위치·반품 요청ID·원건 재확인 함께 유지.
- 검색/내역: main 쉼표 OR·초기 재고 표시와 후보 guarded membership·취소/위치 표시 유지.
- 공개 API·새 업무 정책을 추가하지 않으며 기존 migration을 삭제/변조하지 않음.
- 기존 검증은 소스/입력에 유효한 범위만 재사용. 전체 로컬 업무 검사를 반복하지 않음. CI 설정은 유지.
