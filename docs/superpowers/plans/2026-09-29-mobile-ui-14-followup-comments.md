## 두 선택 화면 조사

- 변경: `MobileWorkTypeStep`의 창고 입출고와 기존 세로 방향 선택, `MaterialDirectionStep`의 모바일 방향 선택. `.twoChoices` 공통1열·2행·최소104px·축소 방지.
- 원자재 방향 부모의128px 최소 높이를 내용 높이 보존 구조로 바꿔 짧은 화면에서 다음 버튼과 겹치지 않게 했다.
- 불량 폐기/재작업·부서/창고 출처, 격리 등록/바로 처리는 이미 세로 목록이므로 유지했다.
- AS/연구 부서 입력, 저장/검토 버튼, 출하 정보 필드, 품목 내부 BOM 옵션·재고 출처, 탭·지도는 큰 업무 선택 카드가 아니므로 유지했다.
