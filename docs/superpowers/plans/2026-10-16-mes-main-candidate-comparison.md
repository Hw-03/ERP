## CP4 — 병합 판단과 직원 적용을 분리한다

- [ ] 결과 문서는 업무별 `main / 후보 / 의도한 차이 / 실제 차이 / 자동 근거 / 브라우저 근거 / 미검증`으로 제공한다. 사용자 검토용 두 판과 시나리오를 남긴다.

- [ ] 사용자 병합 승인 시 당시 main 보존 브랜치를 원격에 남기고, 검증한 후보 커밋 그대로 반영한다. 검증 후 다른 소스를 추가하지 않는다.

- [ ] 자동 동기화는 C:/ERP의 실제 파일을 사용한다. 검증 워크트리는 자동 배포 대상이 아니지만 실제 C:/ERP에 후보를 반영하면 다음 예약에 영향을 줄 수 있으므로, 병합 승인과 직원 적용 시점·절차도 함께 확인한다.

현재 권장 다음 단계는 CP0의 업무별 차이표와 근거 재사용표 확정이다. 이 문서 작성만으로 검증 실행이나 병합을 시작하지 않는다.
