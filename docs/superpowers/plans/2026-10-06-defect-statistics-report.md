# 대표 보고용 불량 통계 개편

**GOAL:** DEXCOWIN MES 불량 통계를 규모·증감·집중 영역을 한눈에 설명하고 상세 분석할 수 있는 화면으로 개편한다.

## 승인된 범위

- 첫 진입 이번 달 누계·전체 범위. 이후 기간·필터 선택 유지.
- 화면에서 규모·증감·사유 및 품목 집중도를 먼저 보고, 클릭하여 상세 분석.
- PDF·엑셀, 생산량 대비 불량률, 손실금액, 처리 완료율은 제외.
- 기존 발생·중복 제거·현재 분류·레거시 제외 규칙과 기존 통계 API 유지.
- 실제 DB 변경, 브랜치 생성·전환, 커밋·푸시, 동결 화면 변경 없음.

## 구현 계약

- 읽기 전용 `GET /api/defects/statistics/report`: 기존 기간·다중 필터와 선택적 `reason`, `item_id`.
- 기존 응답 필드에 `as_of`, `observed_until`, `is_partial`, `comparison`, `trend` 추가.
- `comparison`에는 이전 기간·실제 종료 시각·기간 보정 여부, 요약 및 사유·부서·품목 집계, 제외 기록, 수량·건수의 절대 증감과 nullable 증감률을 반환.
- `trend`는 선택 기간까지 최근 8주·6개월·3개년의 수량·건수와 시작일·종료일·진행 여부.
- 요청당 서버 시각을 한 번 확정. 발생 데이터를 필요한 범위에서 한 번 읽고 같은 필터와 시점으로 기간별 분배.
- 완료 기간은 직전 전체 기간, 진행 기간은 직전 기간의 같은 요일·날짜·월일과 시각까지 비교.
- 이전 값 0 또는 짧은 달·윤일 보정은 증감률 생략. 미래 날짜를 관측 0으로 표시하지 않음.
- 넓은 조회 범위에서도 선택 기간과 비교 기간의 레거시 제외 건수를 각각 계산.

## 화면과 완료 기준

- 접힌 분류 필터, 선택 조건 해제·초기화, KST 집계 시각과 새로고침.
- 실제 집계값으로 만든 요약 문장과 발생 규모·증감·등록 사유·품목 집중도 카드.
- 최근 추세와 사유별 가로 막대, 선택 기간 상세 추이 전환.
- 부서별 막대 및 이전에만 발생한 품목을 포함하는 품목 비교표.
- 사유·부서·품목 클릭 시 모든 지표를 같은 조건으로 갱신.
- 데스크톱·모바일 모두 조회 조건과 결과가 다르면 이전 결과를 숨김.
- 1366×768 첫 화면에서 요약·핵심 카드·추세·사유 차트 확인. 모바일 한 열, 가로 넘침 없음.
- 미분류·동률·0건·조회 실패·재시도·미래 기간 차단과 키보드 탐색 검증.
