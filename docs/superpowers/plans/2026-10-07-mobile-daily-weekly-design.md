# 일보 화면 맞춤과 주간보고 디자인 정리

**GOAL:** 모바일 일보의 기본 작성 화면을 스크롤 없이 맞추고, 주간보고의 기존 비교표와 업무 흐름을 유지하면서 모바일 디자인을 통일한다.

사용자 승인 계획. 커밋·푸시는 별도 요청 시 진행한다.

## 적용 기준

- 일보 기본 작성 화면은 남은 높이에 맞춘다. 긴 글은 입력창 안에서 스크롤한다.
- 전체 일보·펼친 작업 기록·오류·높이 560px 미만 화면에서는 본문 스크롤을 허용한다.
- MES 작업 기록은 기본 요약을 표시하고 펼치면 기존 작업 종류·거래 상세를 보여준다.
- 날짜·작성자·내/전체 일보·글자 수·저장 상태와 기존 저장·이탈 보호는 유지한다.
- 높이 전환은 편집기를 재마운트하지 않으며 로딩·마스코트도 같은 높이 규칙을 따른다.
- 주간보고는 생산 현황 → 공정 변화 → 선택 공정 품목 순서를 유지한다.
- 모바일 전용 표시로 큰 그림자를 제거하고 토큰 표면·테두리, 모서리 20px, 외부 12px·내부 16px·섹션 12px 간격을 사용한다.
- 2026-10-07 후속 사용자 선택에 따라 생산 현황은 가로 스크롤을 제거하고 모델명 아래 여섯 공정을 3열·2줄로 표시한다. 기존 모델 순서·수치·집계 의미는 유지한다.
- 글씨체는 기존 Pretendard를 상속하고, 품명은 왼쪽·수량은 같은 열의 오른쪽에 정렬한다.
- 2026-10-07 후속 요청에 따라 큰 공정 카드는 부서명·공정 코드만 있는 3열·2줄 선택 버튼으로 줄인다. 집계는 선택 공정 품목 상세의 요약에서 확인한다.
- 품목 상세는 품명·코드·증감과 여섯 수치를 3열 두 줄로 배치한다. 품명 펼침과 BOM 선택 버튼을 중첩하지 않는다.
- 주간보고의 모델·공정 순서, 전체 생산/모델별 집계 구분, 정상/기존 재고 기준, 0 표시·재시도·늦은 응답 보호를 유지한다.
- 출하 요청 아이콘만 `ClipboardPlus` → `FilePenLine`으로 변경한다.

공통 헤더·하단 탭바·PC·주간보고 동결 내부·백엔드·URL 계약은 변경하지 않는다.

2026-10-07 정렬 후속 수정: 생산 현황의 공정명과 수량은 각 셀의 같은 행에서
좌우로 정렬한다. 그룹 선택 상태·순서·품목 및 BOM 조회는 유지한다.

2026-10-07 가독성 추가 요청으로 위 정렬을 대체한다. 생산 수량은 18px로 키우고
공정명을 바로 위에 가운데 정렬하여 옅은 칸 안에 묶는다. 상세 요약은 부서·코드
중복을 제거하고 재고·증감·표시/전체 품목 수를 한 줄로 표시한다. 전주·생산·입고·
출고·불량·현재 수량과 증감이 모두 0인 품목만 숨기며 서버 집계는 수정하지 않는다.
품목 상세의 여섯 수치도 생산 현황과 같은 옅은 칸·가운데 정렬·18px 수량을 사용한다.
주차 선택은 좌우 44px 버튼 사이의 남은 너비를 채우며 달력은 선택 영역의 가로
중앙에 표시한다. 마지막 카드와 탭바 사이 간격은 탭바의 기존 8px를 포함해 12px다.
