## 공통 기준

- Pretendard, 기존 색상 토큰과 상태 의미, lucide 아이콘을 유지합니다.
- 중립 표면과 간결한 행을 사용하며 제목·아이콘·색상 면적을 줄입니다.
- 품명·수량·상태를 우선하고 코드·시간·담당자는 보조행으로 표시합니다.
- 본문 14px, 메타 12px, 입력 16px, 터치 44px를 기준으로 합니다.
- 본문은 가용 폭을 최대 720px까지 사용하고 하단 탭바의 기존 폭은 별도 보존합니다.
- 반복 설명만 줄이고 경고·오류·처리 결과·체크리스트 지시는 보존합니다.
- 공유 컴포넌트는 모바일 표시를 명시적으로 선택하고 기존 기본 출력을 유지합니다.
