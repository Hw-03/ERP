# 재고 상세 패널 디자인 개선

> 2026-10-22 사용자 후속 요청으로 디자인은 [기존 카드형 복원 계획](2026-10-22-inventory-detail-cards.md)으로 대체됐다. 아래 내용은 이전 구현과 검증의 기록이다.

**GOAL:** 사용 가능 수량을 중심으로 예약·입고 예정·위치별 재고·관련 작업을 정돈해, 좁은 상세 패널에서도 쉽게 읽히도록 개선한다.

## 승인된 디자인

- 수량 요약은 기존 표면색과 얇은 테두리, 모서리 20px, 내부 여백 16px로 맞춘다.
- 사용 가능 재고는 12px 라벨, 32px 숫자, 작은 단위로 강조한다.
- 예약과 들어올 예정은 같은 너비의 두 열로 정렬하고 옅은 세로 구분선을 둔다. 라벨은 12px, 숫자는 18px로 통일한다.
- 예약 열 전체를 눌러 상세를 펼친다. 화살표는 라벨 오른쪽에 두고 내역은 아래 전체 너비로 표시한다.
- 확인된 예정 0에는 ‘완료 후 사용’을 생략한다. 예정이 있을 때 설명을 표시하고 불완전 정보의 안내는 유지한다.
- 위치별 재고는 카드로 감싸지 않고 요약 아래에 둔다. 섹션 간격은 16px, 위치 행 높이는 최소 44px다.
- 위치 행은 부서명과 사용 가능 수량을 정렬한다. 실재고와 예약은 12px 보조 정보로 표시하고 행 사이에만 구분선을 둔다.
- 관련 작업이 없으면 ‘관련 작업 — 없음’ 한 줄, 있으면 제목 옆 건수와 기존 펼침 목록을 표시한다.
- PC와 모바일에 같은 정보 위계를 적용한다. 기존 일반 소비자의 위치별 재고 스타일은 유지한다.
