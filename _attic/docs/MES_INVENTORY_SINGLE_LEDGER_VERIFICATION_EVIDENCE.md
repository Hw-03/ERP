# 별첨 1. DEXCOWIN MES 재고 단독 운영 전환 검증 근거

**점검일:** 2026-08-13
**보고 대상:** 이필욱 부장님
**대상 판단:** 엑셀의 신규 재고 기록을 중단하고 DEXCOWIN MES를 재고 업무의 단일 공식 기록으로 전환할 수 있는지 여부

## 1. 이 자료가 확인하는 범위

이 자료는 MES의 주요 재고 변경 로직과 현재 직원 운영 DB의 내부 수량 관계를 점검한 결과입니다. 엑셀을 운영 원장으로 계속 유지해야 하는지 판단하기 위한 근거입니다.

다만 다음 사항을 의미하지는 않습니다.

- 모든 품목의 현재 MES 수량이 실물 수량과 이미 일치한다는 의미는 아닙니다.
- 모든 작업자가 앞으로도 누락이나 오입력 없이 업무를 처리한다는 의미는 아닙니다.
- 점검 대상 밖의 모든 가능한 업무 상황까지 무조건 정상이라고 단정하는 의미는 아닙니다.

현재 실물 기준값의 정확도와 작업자 입력 품질은 별도의 운영 관리 대상입니다. 이는 엑셀을 다시 병행 입력해야 한다는 근거가 아니라, MES 단독 운영 후 표본·순환 실사와 거래 이력 확인으로 관리할 대상입니다.

## 2. 점검 방식과 데이터 보호

### 2.1 기능 점검

- 점검 대상: 직원 운영 환경의 현재 프로그램 소스
- 실행 환경: 각 테스트마다 독립된 메모리 DB를 생성하는 자동 테스트 환경
- 실제 운영 DB 영향: 없음
- 근거: 테스트 설정에서 데이터베이스 연결을 메모리 DB로 고정하고, 테스트 종료 시 생성한 테이블을 제거하도록 구성되어 있습니다.

### 2.2 운영 데이터 정합성 점검

- 점검 대상: 직원 운영 DB의 현재 재고 데이터
- 점검 방식: 음수 재고, 예약 수량, 위치별 수량 합계, 고아 데이터, 장기 미처리 예약 등 조회 전용 검사
- 실제 운영 DB 영향: 없음

| 점검 항목 | 확인 결과 | 의미 |

| 고아 위치·재고·거래 | 0건 | 연결 대상이 없는 재고·위치·거래 데이터가 없음 |

점검 결과, 현재 운영 DB에서 위 수량 관계를 깨는 오류는 확인되지 않았습니다.

## 5. 확인된 과거 이력 추적 과제

과거 거래 이력 중 **630건**에는 취소 시 위치별 수량을 정확히 역재생하기 위한 `inventory_effect` 기록이 없습니다. 유형별 현황은 수량 보정 15건, 백플러시 279건, 불량 폐기 69건, 분해 12건, 불량 등록 39건입니다.

이는 현재 재고 합계·예약·위치별 수량의 불일치를 뜻하지 않습니다. 실제로 본 점검에서 해당 현재 수량 관계 오류는 0건이었습니다. 다만 이 과거 이력은 나중에 취소가 필요할 경우 자동 역재생 대상인지 별도 확인이 필요합니다. 따라서 다음과 같이 관리합니다.

1. 과거 이력 취소 요청은 거래 이력과 실물·현재 수량을 확인한 뒤 처리합니다.
2. 새로 발생하는 거래는 현재 방식대로 거래 효과와 함께 기록되는지 정기 점검합니다.
3. 이 추적 과제는 엑셀을 다시 운영 원장으로 사용하는 사유가 아닙니다.

## 6. 이 결과가 엑셀 폐기 판단을 뒷받침하는 이유

엑셀은 현재 실물 기준값을 보증하지 못하므로 MES 검증의 기준 장부가 될 수 없습니다. 반면 이번 자료는 재고 변경 로직의 주요 시나리오와 직원 운영 DB의 내부 수량 관계를 직접 점검한 결과입니다.

따라서 엑셀을 계속 입력해 두 장부의 숫자만 비교하는 것보다, MES를 단일 운영 원장으로 정하고 실물 차이는 MES 거래 이력으로 추적하는 방식이 더 검증 가능하고 업무 효율도 높습니다. 엑셀 신규 기록을 중단하면 작업자는 하나의 시스템에서만 입력·조회·수정 요청을 처리하게 되어 이중 입력과 대조 업무가 사라집니다.

## 7. 전환 후 관리 원칙

1. 전환일 이후 재고 변동은 MES에만 기록합니다.
2. 기존 엑셀 파일은 수정하지 않고 과거 이력 확인용 읽기 전용 자료로 보관합니다.
3. 고회전·고가·출하 관련 품목을 중심으로 표본·순환 실사를 실시합니다.
4. 실물과 MES 수량의 차이가 발생하면, 엑셀을 다시 맞추지 않고 MES 거래 이력으로 원인을 확인합니다.
5. 원인이 사용자 입력·업무 절차·시스템 중 어디에 있는지 구분한 뒤, 필요한 경우 관리자 승인 아래 MES 수량을 보정합니다.
6. 표본 실사는 사용자 입력과 업무 절차를 관리하기 위한 운영 감사이며, 엑셀 병행 입력의 조건으로 사용하지 않습니다.
