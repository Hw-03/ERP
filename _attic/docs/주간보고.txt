안녕하세요. 생산부 김현우 사원입니다.
2026.08.08 ~ 08.21 MES 개발 현황을 보고드립니다.
업무에 늘 수고가 많으십니다.

이번 기간엔 엑셀 병행 기록을 중단하고, MES를 재고 업무의 단일 공식 기록으로 전환하였습니다. 앞으로 입고·출고·불량·출하 등 재고와 관련된 모든 업무는 MES 한 곳에서만 처리하시면 됩니다.

이미 사용해보신 부분이지만, MES 전환으로 몇 가지 불편이 함께 해소됩니다.

1. BOM 기준으로 입출고하면 구성품이 누락 없이 한 번에 처리되어 실수가 줄어듭니다.
2. NAS 엑셀 파일을 여러 명이 동시에 열지 못해 겪던 불편함도 사라집니다.
3. MES는 음수 재고를 허용하지 않아 엑셀 관리 중 간혹 있었던 재고 마이너스 표시 문제도 없어집니다.

다만 현재는 실제 재고 수량과 MES에 입력된 수량이 아직 완전히 같지 않습니다.
이는 시스템이 대신할 수 없고 각 부서에서 직접 실물을 세어 입력해야 하는 부분이라, 
가능한 한 빨리 진행해 주시면 좋겠습니다. 
부서별 재고를 한 번만 정확히 입력해 두고 누락 없이 입출고를 진행하신다면,
엑셀로 관리할 때보다 재고 수량의 신뢰도가 높아진다는 것을 체감하실 수 있을 것입니다.
생산 가능 수량도 바로 확인할 수 있어 타부서에서 생산 수량을 참고하기도 좋아집니다.

각자 진행 중인 업무로 바쁘신 것을 알고 있으니, 여유 되실 때 차근차근 진행해 주시면 감사하겠습니다.

이 외에 생산 가능수량·BOM 화면을 새롭게 개편하고, AS·연구용 사용출고 기능을 확장하였으며, 대시보드 필터·입출고 내역 화면을 비롯한 여러 화면의 사용성과 안정성도 함께 개선하였습니다.

■ 주요 진행 사항 (8/8 ~ 8/21)

1. MES 단독 운영 전환 (8/13)
- 엑셀 병행 기록을 중단하고, MES를 재고 업무의 단일 공식 기록으로 전환하였습니다

2. 생산 가능수량·BOM 화면 개편 (8/19~8/20)
- 완제품(PF)별로 생산 가능수량을 확인할 수 있도록 대시보드와 BOM 화면 구성을 다시 정리하였습니다
- BOM 구성이 아직 안 끝났거나 완제품 경로가 없는 품목은 흐리게 표시하여 구분하기 쉽게 하였습니다
- BOM 구성 보기와 수량 조정 화면의 가독성을 다듬었습니다

3. 기준 출하품 자동 선정 (8/12)
- 생산 가능수량 계산에 쓰이는 기준 출하품을 담당자가 직접 고르던 방식에서, 시스템이 자동으로 선정하는 방식으로 전환하였습니다

4. AS·연구용 사용출고 기능 확장 (8/14~8/18)
- 사용출고에서 BOM 전개와 낱개 선택을 함께 지원하고, 같은 품목을 여러 번 고르면 마지막 선택만 적용되도록 정리하였습니다
- AS·연구 목적으로 자재를 사용 출고할 때 어느 위치 재고에서 차감할지 지정할 수 있도록 구현을 완료하였습니다

5. 대시보드 필터 개선 (8/10~8/19)
- 대시보드 품목 목록에서 여러 조건을 모두 만족(AND)하거나 하나만 만족(OR)해도 되는 필터 조건을 새로 추가하였습니다
- 여러 조건을 함께 걸었을 때 결과가 정확하게 걸러지지 않던 문제와, 불용 품목 필터가 다른 조건과 함께 걸릴 때 어긋나던 문제를 여러 차례에 걸쳐 바로잡았습니다

6. 재작업 취소 안전성 보강 (8/14)
- 재작업 묶음을 취소할 때 발생하던 오류를 바로잡고, 처리가 안 될 때는 원인을 안내 문구로 보여주도록 개선하였습니다

7. 입출고 내역 시각·표시 오류 수정 (8/14, 8/19)
- 입출고 이력에 표시되는 시각과 월별 조회 기준이 기기 설정에 따라 다르게 보이던 문제를 한국 시간 기준으로 고정하였습니다
- 화면이 실시간으로 갱신될 때 깜빡이던 현상을 없애고, 수량 증감 표시가 틀리던 문제를 수정하였습니다

8. 입출고 내역 화면 시각 정리 (8/19~8/20)
- 입출고 내역 표의 모서리·스크롤바 표시와 담당자 열, 작성 간격을 다듬어 화면을 더 깔끔하게 정리하였습니다

9. 재고 예약·부족 처리 개선 (8/10~8/13)
- 예약된 재고와 실제 출고 가능한 수량을 구분해서 보여주도록 개선하였습니다
- 부서 승인 대기 중인 재고도 예약 처리에 반영하고, 창고 승인 시 재고가 부족하다고 잘못 뜨던 오류를 수정하였습니다

10. 입출고 입력 방식 개선 (8/10~8/18)
- 창고 수량보정 입출고를 새로 추가하고, 신규 품목을 초기 재고 0으로도 등록할 수 있게 하였습니다
- 품목 선택 방식과 낱개 부서 입출고의 메모 입력, 수량·최종 확인 화면의 정렬을 정리하였습니다

11. BOM 완료 잠금 (8/14)
- 완료 처리된 BOM은 실수로 수정되지 않도록 잠그는 기능을 추가하였습니다

12. 관리자·전 메뉴 UI 정비 (8/10, 8/18)
- 관리자 화면을 포함한 전 메뉴의 화면 요소(탭 테두리, 사이드바 전환, 카드 표시 등)를 다듬는 작업을 이어갔습니다

13. 일일 작업 일보 안정화 (8/10)
- 일일 작업 일보의 달력 팝업과 저장 상태 동기화 문제를 바로잡았습니다

14. 조립 체크리스트 데이터 동기화 보정 (8/12)
- 모바일 조립 체크리스트의 기존 데이터를 최신 항목 구성과 맞도록 동기화하였습니다
