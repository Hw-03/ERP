■ 주요 진행 사항 (8/29 ~ 9/4)

1. 낱개 입출고 — BOM 하위자재 커스텀 선택 기능 신설 (8/31~9/2)
- 낱개로 입출고할 때 BOM을 참고해서 필요한 하위자재만 커스텀으로 골라 처리할 수 있는 기능을 새로 만들어, 입출고를 더 원활하게 진행할 수 있게 하였습니다
- 기본 BOM은 그대로 즉시 처리되고, 커스텀 BOM·낱개 작업은 메모를 반드시 남기고 부서 결재를 거치도록 통일하였습니다
- 기능을 만드는 과정에서 BOM 반복 증감 계산 오류, 생산 입고 혼합 처리 오류, 하위 품목 재선택 시 수량이 맞지 않던 문제를 함께 수정하고, 입고·출고 양쪽에서 같은 방식으로 동작하도록 정리하였습니다

2. 불량 격리 검색 기능 신설 (9/1)
- 격리 처리해야 할 품목이 많아짐에 따라, 여러 조건으로 한 번에 찾을 수 있는 검색창과 검색 결과가 없을 때의 화면을 추가하였습니다

3. 일일 작업 일보 날짜 이동 개선 (9/2)
- 날짜를 하루씩 이동할 때 주말은 건너뛰도록 개선하였습니다

4. 품목 전환 구성 비교 기준 단순화 (9/3)
- 품목을 다른 품목으로 전환할 때 구성품 차이를 직계 구성품 기준으로만 비교하도록 정리하여, 하위 BOM까지 파고들어 복잡하게 보이던 것을 더 단순하고 예측 가능하게 만들었습니다

5. 주간보고 화면 정확도 개선 (8/31, 9/3)
- 주간보고 화면의 날짜 기준과 버튼 배치를 정리하고, 품목 전환 건의 집계가 정확히 반영되도록 수정하였습니다

6. 화면 정리 (9/1~9/3)
- 상태 알림 표시 방식을 통일하고, 격리 기록·재고 변동 수량 표시와 입출고 작성 중 작업 표를 다듬었습니다
