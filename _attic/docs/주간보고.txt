이번 주엔 조립 품질 검증을 위한 모바일 체크리스트 기능을 새로 추가하고, 자재 입출고관리대장·연간 생산일지 자동 생성 기능을 준비하였으며, 영업부와 출하 관련 회의를 거쳐 정리한 개선 요청 반영에 착수하였습니다. 관리자·대시보드·입출고 내역 화면 등 UI도 계속 다듬어 나가며 사용성을 높여나가고 있습니다.

───────────────────────────────────────────────────────────

■ 주요 진행 사항 (7/17 ~ 7/24)

1. 모바일 조립 체크리스트 신설 (7/22~7/24)
- 나사 체결 등 조립 작업을 마치기 전, 작업자 본인이 아닌 다른 담당자가 교차 확인하여 조립 품질을 검증할 수 있도록 체크리스트 화면을 모바일에 새로 만들어 더보기 메뉴에 추가하였습니다
- 완료 표시와 항목 관리·삭제 기능을 이어서 추가하였습니다

2. 자재 입출고관리대장·연간 생산일지 자동 생성 기능 (진행 중, 7/24)
- 자재 입출고관리대장과 연간 생산일지를 정해진 양식의 엑셀 파일로 바로 내려받을 수 있는 기능을 추가하고 있습니다

3. 관리자 목록·탐색 구조 개편 (진행 중, 7/21~7/23)
- 관리자 화면의 목록·상세 정보 배치와 탐색 구조를 정리하여 원하는 정보를 더 빠르게 찾을 수 있게 하였습니다
- 모델 목록과 상세 영역의 화면 비율, 직원·부서 상세의 높이 배분을 다시 정리하였습니다

4. 관리자 화면 시각적 통일 (진행 중, 7/22~7/23)
- 품목·부서·직원·모델 등 여러 관리 화면의 표시 방식을 통일하였습니다
- 목록과 BOM 작업대의 시각적 표현, 공통 레이아웃의 여백과 버튼 배치를 정리하였습니다

5. 입출고 내역 담당자·상세 패널 정비 (7/20~7/21)
- 담당자 표시와 우측 상세 패널을 다듬고, 완료 이력의 필터·정렬을 개선하였습니다
- 이력 표현과 부서 분류 방식을 정비하였습니다

6. 입출고 내역 탭 전환 속도 개선 (7/20)
- 입출고 내역 탭을 전환하는 방식을 정리하여 화면이 더 빠르게 열리도록 개선하였습니다

7. 대시보드 세션·상세 화면 정리 (7/21~7/22)
- 대시보드 로그인 세션 표시와 상세 화면 구성을 정리하였습니다

8. 생산 가능수량 팝업 정리 (7/21)
- 생산 가능수량 팝업의 모델 구조를 정리하고, 입출고 카드가 화면 크기에 맞게 배치되도록 개선하였습니다

9. 출하·창고 사용성 개선 (7/22, 7/24)
- 출하 수량을 버튼으로 늘리고 줄일 수 있는 조작 방식을 다듬었습니다
- 창고 작업을 이어서 진행할 때 저장된 단계로 정확히 돌아가지 않던 문제를 수정하였습니다

10. 출하 관리 — 영업부 요청 반영 착수 (진행 중, 7/24)
- 영업부와 출하 관련 회의를 거쳐 실제 업무 방식에 맞는 개선 방향을 정리하였고, 이를 바탕으로 출하 요청에 인보이스 번호를 입력하는 단계와 요청 수정 이력을 남기는 기능을 반영하는 작업에 착수하였습니다
- 준비 중인 요청이 수정되면 모바일 작업자에게 변경 사실이 표시되도록 하고, 영업부가 확인해야 하는 품목을 구분해 표시하는 방향도 함께 준비하고 있습니다

시스템은 제 자리 PC가 켜져 있을 때 http://192.168.0.63:3000 에서 확인하실 수 있습니다.
