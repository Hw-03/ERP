2026.10.09 ~ 10.23 MES 개발 현황을 보고드립니다.
업무에 늘 수고가 많으십니다.

불량 통계와 처리, 관리자 화면을 다듬고 입출고 방향 안내와 작업 내역 확인을 개선하였습니다.
전수조사 중 기존 작업을 보존해 조사 반영 후 이어갈 수 있도록 했으며, 출하 담당자 입력과 공유 작업 현황을 정리하였습니다.
부족 자재의 확보 가능 수량만 예약하고 전량 확보 전 제출을 제한하는 기능은 보완 중이며, 로그인 로고 표시도 다듬었습니다.

───────────────────────────────────────────────────────────

■ 주요 진행 사항 (10/9 ~ 10/16)

1. 재고 전수조사 회차와 조사 대상 확인 개선 (10/14~10/15)
- 새 조사 회차를 시작하고 조사 대상 품목과 참여자를 확인할 수 있도록 하였습니다
- 회차가 없을 때는 최근 종료 결과를 확인할 수 있도록 대기 화면을 정리하였습니다

2. 전수조사 수량 입력·검토와 결과 확인 개선 (10/14~10/15)
- 조사 수량과 진행 상황, 위치별 차이를 확인하고 입력 내용을 검토할 수 있도록 하였습니다
- 반영 대기, 전체·부분 종료 결과와 최근 조사 내역을 확인하고 조사 자료를 내려받을 수 있도록 하였습니다

3. 품목 검색어 관리와 검색 방식 통합 (10/14~10/15)
- 품목별 별칭과 공통 동의어를 등록해, 익숙한 이름으로도 품목을 찾을 수 있도록 하였습니다
- 컴퓨터와 모바일의 품목 검색에서 같은 검색어 기준을 사용하도록 정리하였습니다

4. 품목 최근 이력과 작업 상세 확인 개선 (10/12~10/15)
- 품목별 최근 재고 이력과 작업 결과를 날짜순으로 함께 확인하고 필요한 기록을 더 조회할 수 있도록 하였습니다
- 작업별 처리 결과와 취소 사유, 내 작업 내역을 찾기 쉽게 정리하였습니다

5. 불량 처리 화면과 단계 안내 개선 (10/15)
- 불량 처리 단계를 구분하고 색상과 품목별 수량을 정리해 현재 처리 상태를 알아보기 쉽게 하였습니다
- 품목 목록과 입력 조작 영역을 넓혀 처리할 항목을 확인하기 쉽도록 개선하였습니다

6. 같은 품목의 사유별 불량 격리 등록 개선 (10/12)
- 한 품목에 여러 불량 사유가 있을 때 사유별 수량을 나누어 한 번에 등록할 수 있도록 하였습니다
- 모바일에서도 품목과 사유별 수량을 확인하고 입력하기 쉽게 정리하였습니다

7. 격리 불량의 정상 복귀 위치 보완 (10/16)
- 창고 격리 재고를 정상 복귀할 때 창고 수량으로 돌아가도록 수정하였습니다

8. AS·연구용 사용출고의 차감·반환 방식 안내 (10/15)
- 구성품 사용 시 상위 품목 차감과 사용하지 않은 하위 품목 반환 방식을 처리 전에 확인할 수 있도록 안내를 추가하였습니다

9. 컴퓨터·모바일 알림 화면과 로그인 알림 설정 통일 (10/13)
- 컴퓨터와 모바일에서 공통 알림 화면을 사용하고, 로그인 시 알림을 표시할지 직원이 설정할 수 있도록 하였습니다

10. 공통 재고 화면과 모바일 작업 전환 개선 (10/14)
- 재고 목록의 표시와 모바일 검색 도구를 정리하고, 컴퓨터와 모바일 화면을 오갈 때 작성 중인 입력 내용을 보호하도록 하였습니다

■ 주요 진행 사항 (10/19 ~ 10/23)

11. 불량 발생 통계와 기간별 비교 개선 (10/19)
- 기간별 발생 현황과 이전 기간 대비 변화를 확인하고, 분류·품목·시간대별 수량을 살펴볼 수 있도록 하였습니다

12. 불량 처리 단계와 수량 확인 개선 (10/19~10/20)
- 처리 단계와 다음 작업을 구분하고, 선택한 품목과 처리 수량을 한눈에 확인할 수 있도록 정리하였습니다
- 처리할 품목을 찾고 입력하는 화면 배치도 다듬었습니다

13. 관리자 목록과 정보 입력 화면 개선 (10/19~10/21)
- 품목·모델·직원·부서 정보를 찾고 수정하기 쉽도록 목록과 상세 화면의 배치를 정리하였습니다
- 목록을 불러오는 동안 진행 상태를 확인할 수 있도록 표시를 보강하였습니다

14. 권한 변경 시 진행 중인 업무와 입력 내용 보존 (10/19)
- 직원 권한을 바꾸면 로그인 중인 화면에도 변경 사항이 반영되도록 하였습니다
- 권한이 바뀌어도 작성 중인 내용과 진행 중인 결재가 사라지지 않도록 개선하였습니다

15. 품목 검색과 작업 내역 확인 개선 (10/19~10/21)
- 여러 검색어를 함께 입력하거나 등록된 검색어를 활용해 품목을 더 쉽게 찾을 수 있도록 하였습니다
- 작업 내역에서 품목명을 복사하고 검색 결과를 확인하기 쉽도록 정리하였습니다

16. 입출고 방향 안내와 작업 취소 확인 개선 (10/20~10/22)
- 입고와 출고 방향을 컴퓨터와 모바일의 각 작업 단계에서 같은 색상으로 구분하였습니다
- 요청자가 승인된 작업을 취소할 수 있도록 하고, 출하 예약 등으로 취소할 수 없는 경우 안내를 보강하였습니다

17. 작업 예약·공유 작업 확인과 부족 자재 처리 개선 (10/22~10/23)
- 작업에 필요한 재고를 예약하고, 공유 작업의 진행 상태와 상세 내용을 한곳에서 확인할 수 있도록 하였습니다
- 자재가 부족한 작업도 확보 가능한 수량만 예약하고, 필요한 수량이 전부 확보되기 전에는 제출을 막도록 보완하고 있습니다

18. 전수조사 대기 화면과 작업 이어하기 개선 (10/20~10/23)
- 조사할 회차가 없을 때 다음에 확인할 내용을 알아보기 쉽게 정리하고, 대시보드와 목록을 불러오는 동안 화면 배치가 급격히 바뀌지 않도록 개선하였습니다
- 조사 중에는 기존 작업의 내용과 수량을 보존하고 관련 예약을 해제했다가, 조사 반영 후 이어서 진행할 수 있도록 하였습니다

19. 로그인 화면 로고 표시 개선 (10/23)
- 로그인 화면이 열릴 때 로고가 자연스럽게 나타나도록 하고, 모바일에서 로고와 로그인 영역의 배치를 정리하였습니다

20. 출하 작업자 입력과 전체 작업 확인 개선 (10/23)
- 출하 작업 담당자를 입력하고, 진행 중인 전체 작업을 한곳에서 확인할 수 있도록 정리하였습니다
