이번 기간엔 불량 격리 처리 이력을 남기는 기능을 새로 만들고, 출하 요청 흐름을 단순화하였습니다. 이 외에 대시보드·입출고 내역 화면과 재고 집계 정확도도 함께 개선하였습니다.

───────────────────────────────────────────────────────────

■ 주요 진행 사항 (8/22 ~ 8/28)

1. 불량 격리 기록 기능 신설 (8/24~8/28)
- 불량 격리 처리 이력을 별도로 기록하고, 메모까지 남겨 조회할 수 있는 기능을 새로 만들었습니다
- 격리 목록에서 품목별로 접어서 볼 수 있게 하고, 취소·복원된 기록도 정확히 구분되어 표시되도록 정비하였습니다
- 부서·격리자·정렬 조합을 필터로 저장해, 다음에 들어와도 같은 조건으로 바로 볼 수 있게 하였습니다

2. 출하 요청 흐름 단순화 (8/24)
- 출하 요청을 만들면 바로 준비 단계로 넘어가도록 흐름을 단순화하고, 더 이상 쓰지 않는 상태 값을 정리하였습니다
- 출하 요청 목록 화면의 구성도 함께 정리하여 상태를 더 알아보기 쉽게 하였습니다

3. 입출고 내역 전후 재고 표시 (8/24)
- 입출고 내역에서 처리 전후 재고 수량을 함께 볼 수 있도록 표시를 추가하였습니다
- 재고 수량이 표시되는 열의 여백을 넓혀 다섯 자리 숫자까지 잘리지 않고 보이도록 하였습니다

4. 주간보고 재고 집계 정확도 개선 (8/24, 8/26~8/27)
- 주간보고에 표시되는 재고 수치의 계산 기준과 검증 방식을 여러 차례 보강하여 집계 정확도를 높였습니다
- 각 수치가 실제 어떤 거래 기록에서 나온 값인지 근거까지 함께 확인할 수 있도록 보강하였습니다

5. 일일 작업 일보 날짜 이동 편의 개선 (8/26)
- 전일·다음 날 화살표 버튼을 추가하여, 날짜 선택 팝업을 열지 않고도 하루씩 편하게 이동할 수 있게 하였습니다

6. 대시보드 개선 (8/25~8/27)
- 부서로 필터링할 때, 재고가 있는 위치 기준으로 볼지 품목 코드에 지정된 부서 기준으로 볼지 선택할 수 있게 하였습니다
- 품목별로 최근 취소된 내역을 바로 확인할 수 있는 항목을 추가하였습니다
- 최근 내역에 표시되는 작업 수량을 더 보기 쉽게 다듬었습니다

7. '빠른 생산' 수량 표시 오류 개선 (8/27)
- 완제품 재고가 있는데도 포장 단계 품목 경로가 제대로 인식되지 않아 '빠른 생산' 수량이 0으로 표시되던 문제를 바로잡았습니다

8. 입출고 수정 재제출 오류 수정 (8/28)
- 승인 전 요청을 수정해서 다시 제출할 때 내용이 어긋나던 문제를 바로잡았습니다

9. 취소 내역 화면 정리 (8/28)
- 취소 확인 화면에 위험을 강조하는 색상을 적용하여 무엇을 취소하는지 더 분명하게 보이도록 하였습니다
- 취소 버튼을 누를 수 없는 상태일 때의 표시를 명확하게 하여 오조작 가능성을 줄였습니다

10. BOM 선택 출고·반려 요청 이어서 작성 (8/26)
- BOM 구성품 중 원하는 하위 품목만 골라 출고할 수 있게 하고, 부서 결재·예약 확인 방식을 통일하였습니다
- 반려된 요청을 다시 열면 작성 중이던 내용부터 이어서 수정할 수 있게 하였습니다

11. 입출고 내역 표시 정확도 개선 (8/26)
- 취소된 거래와 원래 거래가 한 줄에 섞여 보이던 것을 분리해서 표시하였습니다
- 화면에 보이는 수량을 실제 처리 기록 기준으로 통일하여 실제 이력과 표시 수치가 일치하도록 하였습니다

시스템은 제 자리 PC가 켜져 있을 때 http://192.168.0.63:3000 에서 확인하실 수 있습니다.
