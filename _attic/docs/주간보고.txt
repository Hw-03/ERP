업무에 늘 수고가 많으십니다.

원자재 입고부터 결재 전 요청 수정·입출고 내역 확인까지 현장에서 자주 쓰는 흐름을 개선하고, 업무 화면의 전환과 안내도 더 알기 쉽게 정리하였습니다.

───────────────────────────────────────────────────────────

■ 주요 진행 사항 (9/12 ~ 9/23)

1. 원자재 입고 공급업체 관리 신설 (9/22)
- 원자재를 입고할 때 등록된 공급업체를 선택하거나 새 공급업체를 바로 추가할 수 있게 하였습니다
- 선택한 공급업체가 입고 기록과 자재 입출고관리대장에 함께 남아, 어느 업체에서 들어온 자재인지 이력으로 확인할 수 있습니다

2. 결재 전 입출고 요청 수정 개선 (9/22)
- 결재 전 요청을 수정하면 기존 요청을 안전하게 취소하고 변경한 내용으로 다시 제출되도록 흐름을 정리하였습니다

3. AS·연구용 사용출고 결재 흐름 추가 (9/16)
- AS·연구 목적으로 자재를 사용 출고할 때 담당 부서의 결재를 거치도록 하였습니다
- 결재가 끝난 알림은 자동으로 읽음 처리되어, 처리된 요청이 미확인 알림에 남지 않도록 하였습니다

4. 입출고 내역 작업명 검색 추가 (9/21)
- 입출고 내역에서 생산·분해·사용출고 등 작업명을 검색해 필요한 기록을 더 빨리 찾을 수 있습니다

5. 입출고 작업 묶음·재고 표시 개선 (9/15, 9/23)
- 같은 작업에서 함께 처리된 품목을 한 묶음으로 알아보기 쉽게 정리하였습니다
- 품목별 최근 입출고 내역에서도 작업 종류와 처리 전후 재고를 같은 기준으로 확인할 수 있도록 표시를 정리하였습니다

6. 출하 내역과 완료 수량 확인 개선 (9/15~9/21)
- 출하 이력에 대표 품목이 분명하게 표시되고, 완료 수량의 집계 기준을 통일하였습니다
- 실제 픽업한 작업자가 기록에 남아 출하 처리 담당자를 확인하기 쉬워졌습니다

7. 미배치 원자재 정리 기능 신설 (9/20)
- 아직 BOM에 배치되지 않은 원자재를 불용·보류·중복으로 나누어 표시하고 관리할 수 있게 하였습니다
- 처리한 건수와 남은 건수를 화면에서 바로 확인할 수 있으며, 불용 처리를 해제하면 이전 분류로 복원됩니다

8. 입고·출고 방향 선택과 낱개 입고 화면 개선 (9/14, 9/22)
- 입고와 출고 카드에 서로 다른 덱스레이 이미지를 적용하고 색상과 선택 표시를 구분해, 작업 방향을 한눈에 알아보고 잘못 선택하는 일을 줄일 수 있도록 하였습니다
- 커스텀 BOM으로 낱개 입고한 품목이 지정한 경로와 수량대로 처리되도록 보완하였습니다

9. 내역 조회와 화면 갱신 개선 (9/17, 9/21)
- 조회에 문제가 생겼을 때 내역이 없는 것처럼 잘못 보이지 않도록 안내를 구분하였습니다
- 입출고 내역을 불러오는 속도를 개선하였습니다

10. 탭 이동·로딩·빈 화면 안내 개선 (9/21~9/23)
- 다른 탭에서 돌아오거나 같은 탭을 다시 눌렀을 때 각 업무 화면의 첫 화면으로 자연스럽게 복귀하도록 정리하였습니다
- 데이터를 불러오는 동안 화면이 비어 보이지 않도록 안내 표시를 정리하고, 내역이 없을 때도 상황을 쉽게 알아볼 수 있도록 화면을 개선하였습니다
- 작성 중인 내용이 있을 때 화면을 이동하면 저장되지 않은 내용을 확인하도록 하여 실수로 작업을 잃는 일을 줄였습니다
