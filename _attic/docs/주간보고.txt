───────────────────────────────────────────────────────────

■ 주요 진행 사항 (7/25~7/28, 8/3~8/7)

1. 출하 요청 인보이스·이력 관리 개선 (7/27~8/7)
- 인보이스 번호를 먼저 입력하고, 아직 번호가 없으면 비워둔 채 준비까지 진행할 수 있게 하였으며, 준비 완료 처리 전에는 인보이스 번호 입력을 필수로 하였습니다
- 요청이 수정되면 수정자·시각·변경 내용이 이력으로 남고, 모바일 작업자 화면에도 수정됨 표시와 변경 요약이 함께 뜨도록 하였습니다
- 영업 확인이 필요한 품목을 미리 지정해두면 출하 작성 화면에서 강조 표시되고, 완료·취소 이력을 연도·월별로 찾아보고 인보이스 번호나 품명으로 검색할 수 있게 되었습니다
- 요청 목록을 새로고침하는 과정에서 작성 중이던 인보이스 번호가 지워지던 문제를 수정하였습니다 (8/3)
- 픽업 완료 처리를 잘못했을 때 준비 완료 상태로 되돌릴 수 있게 하였고, 부족한 재고는 출하 화면에서 바로 창고 재고를 담아올 수 있게 하였습니다 (8/4)
- 출하 준비 시 이전에 사용했던 BOM 구성을 다시 선택해서 재사용할 수 있게 하였습니다 (8/7)

2. 일일 작업 일보 MES 도입 (7/28~8/6)
- 기존에 엑셀로 작성하시던 개인별 일일 작업 일보를 MES 안에서 작성할 수 있도록 새로 만들었습니다
- 저장 방식과 화면 여백, 작업 내역의 높이·가독성을 이어서 다듬었고, 작성 내용이 없을 때의 화면도 정리하였습니다

3. 관리자 내보내기 화면 정리 — F704-02·F705-02 (8/3~8/4)
- 자재 입출고관리대장(F704-02)과 연간 생산일지(F705-02)를 내려받는 내보내기 화면을 정리하고, 별도로 흩어져 있던 BOM 다운로드 기능을 한 화면에서 함께 사용할 수 있도록 통합하였습니다
- 자재 입출고관리대장(F704-02) 양식과 비고란 표시를 정리하고, 다운로드한 엑셀 파일이 열리지 않던 문제를 수정하였습니다

4. 설정 화면 통합 — 테마·사이드바 한 곳에서 관리 (8/4~8/7)
- 화면 테마와 사이드바 고정 여부를 각자 따로 바꾸던 것을 설정 화면 하나로 모았습니다
- 직원마다 사이드바를 고정해두는 방식을 새로 지원하였고, 설정 화면의 목록 구성과 조작 방식을 이어서 다듬었습니다
- 팝업 형태였던 설정 화면을 사이드바의 일반 탭으로 전환하여 더 쉽게 열어볼 수 있게 하였습니다 (8/7)

5. 화면 색상 테마 개선 — 다크 모드·부서별 색상 (8/4~8/5)
- 다크 모드의 색상 체계를 개선하고, 부서별로 구분되는 색상의 대비와 배색을 조정하여 더 잘 구별되도록 하였습니다

6. 품목 표시 순서 통일 (8/4~8/6)
- 화면마다 다르게 보이던 품목 표시 순서를 하나의 기준으로 통일하였습니다
- 품목을 검색하는 중에 순서가 갑자기 바뀌는 문제를 막고, 품목 등록 시 필수 입력값과 표 정렬을 정비하였습니다

7. 화면 실시간 갱신 적용 (8/4)
- 출하·입출고·재고·품목·불량·이력 등 여러 화면에서 다른 사람이 변경한 내용이 즉시 반영되도록 하였습니다. 작성 중이던 내용은 그대로 보존됩니다
