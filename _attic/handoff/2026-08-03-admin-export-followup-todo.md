- 확정 정책: 첫 화면의 독립 작업 카드는 F704-02, F705-02, `데이터 내보내기`, `내부 원본 로그 (월별)`의 정확히 4개만 둔다. `선택 데이터 내보내기 (CSV)`와 `품목·입출고 Excel`은 `데이터 내보내기` 하나로 합치고, 별도 Excel 카드·최근 내보내기 카드·상단 바로가기·헤더 포함 선택은 제거한다. 품목·입출고·직원·BOM과 현재 지원 형식은 잃지 않는다. 원본 로그는 데이터 카드와 분리하고 항상 펼쳐 둔다.
- 구현 방향: `AdminExportSection`에서 범위·형식·조건부 옵션·실행 상태를 한 `ExportSurface`로 합친다. 품목·입출고를 선택했을 때만 기존 Excel 형식을 함께 제공하고, 직원·BOM은 현재 CSV 형식만 표시한다. 데이터 범위에 맞지 않는 기간·비활성 옵션은 숨기고 헤더는 항상 포함한다. 세션 기록 상태와 전용 최근 기록 표면, 독립 Excel 실행 핸들러·표면, 상단 바로가기와 관련 ref를 제거한다. `AdminAuditCsvSection`의 F704 카드는 공식 서식 행으로 분리하고 남은 원본 로그 목록은 독립 다운로드 카드로 재구성한다. 기존 백엔드 다운로드 API와 고유 데이터 컬럼은 유지한다.
- 수용 기준:
  - 첫 화면에서 독립된 작업 카드는 F704-02, F705-02, `데이터 내보내기`, `내부 원본 로그 (월별)` 4개만 보인다.
  - `선택 데이터 내보내기 (CSV)`, `최근 내보내기`, `품목·입출고 Excel`, `시스템 원본 로그 관리`가 별도 상위 카드로 반복되지 않는다.
  - 품목·입출고·직원·BOM 중 필요한 범위와 현재 지원 형식을 `데이터 내보내기` 한곳에서 구분해 선택할 수 있다.

  - 기존 거래 Excel의 기간과 상세 거래 필드가 누락되지 않는다.
  - 헤더는 모든 범용 파일에 포함되며, 데이터 범위와 무관한 옵션은 보이지 않는다.
  - 내보내기 실행 결과와 오류는 세 번째 카드 안에서 즉시 확인할 수 있고 새로고침 시 사라지는 별도 기록 표는 없다.

### 3. 보조 설명·요약을 제거하고 제목 크기와 정렬을 강화

- 원본 코멘트: 후속 브라우저 코멘트 1~2번과 최신 브라우저 코멘트 1~8번.
- 화면/영역: 데스크톱 관리자 > 시스템 > 내보내기의 페이지 헤더, F704-02·F705-02, 통합 데이터 내보내기, 내부 원본 로그 관리와 월별 목록.
