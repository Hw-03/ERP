# DEXCOWIN MES 후속 검증 과제

2026-10-10 사용자가 이번 종료 범위에서 분리한 항목이다. 현재 상태는 미착수이며 이번 작업에서 추가 최적화나 전체 재실행을 진행하지 않는다. main 반영·직원 배포도 승인된 작업에 포함되지 않는다.

## 현재 기록

- 성능 근거: `docs/superpowers/specs/2026-10-10-mes-scoped-performance-results.json` 및 그 문서가 연결한 n5 원문. 아래 수치는 해당 실행의 역사적 측정값이다.
- 일반 품목·상세의 국소 상대 회귀 기준과 관련 pytest는 통과했다. 이 결과를 무거운 조회의 절대 상한 통과로 확대하지 않는다.
- 현재 기대값 원장의 실행과 과거 실행은 구분한다. 원장 생성·연결 검사 및 CI 통과가 현재 전체 업무 기대값 실행을 뜻하지 않는다.

## 후속 체크리스트

- [ ] 내역 묶음 조회의 부하별 절대 상한: n5 실자료 동시 10명에서 메인 p95 15,249.238ms → 작업본 4,116.804ms로 개선됐지만 2초 기준은 FAIL이다. 기존부터 느리던 경로를 모든 부하에서 2초로 만드는 목표는 후속 과제다.
- [ ] 정합성 전체 조회의 부하별 절대 상한: 같은 실행에서 메인 p95 34,285.347ms → 작업본 14,938.241ms이며 10초 기준은 FAIL이다. 조회 범위·숫자·실제 위치 수량을 축소해서 통과시키지 않는다.
- [ ] 동시 30명 성능 측정: NOT_RUN이다. 이전 실패 후보 n6/n7도 원문을 보존하며 채택 코드의 통과 근거로 합산하지 않는다. 자료량별·부하별 전체 완료 판정은 별도 실행 후에만 한다.
- [ ] 현재 기대값 전체 재실행 및 엄격 완료: 현재 실행은 NOT_RUN이며 c13 실행은 historicalExecutions로 보존했다. 새 실행 ID·소스/환경 근거로 검증하고 누락·SKIP·PARTIAL·FAIL·NOT_RUN을 현재 PASS로 바꾸지 않는다.
